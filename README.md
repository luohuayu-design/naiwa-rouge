# 蛙步 · 夜行（naiwa-rouge）

一个用 Three.js 做的**幸存者类肉鸽游戏**原型。角色是「奶蛙」，来自同作者的音游《蛙步》。纯静态站点（无构建、无 CDN、零依赖，Three.js r160 本地内置），GitHub Pages 发布，手机浏览器兼容是硬约束（不用 importmap / 顶层 await）。

在线试玩：<https://luohuayu-design.github.io/naiwa-rouge/>

当前完成第 59 块（**v=69**）：标题页 + 新手教程 + 3D 角色 + 浮动摇杆 + 主角/武器两套独立属性 + 20 回合关卡（4 关）+ 升级成长（28 卡五档品质）+ 武器系统（环剑 + 6 种元素剑 + 箭雨）+ 金币/商店 + 随机事件（112 个，对话普遍 100~180 字）+ 音效与 BGM + 图鉴/成就/战绩/难度 + 篝火局外成长 + 局外商店·宝箱 + 永夜火种 + 夜行诅咒 + 今日挑战/种子 + 礼包兑换 + 公告/宣传有礼 + 每日签到 + 主线剧情《笑不出来的那一夜》+ 管理员模式。

**回合事件一览**见 [`关卡事件表.txt`](关卡事件表.txt)（由脚本从代码生成，含升级概率 / 商店价目 / 元素剑图鉴 / 随机事件表）。

## 玩法

- **场景 / 移动**：深夜草地圆形竞技场，可走半径 15（撞边沿切向滑走）。左半屏按住拖动出浮动摇杆；WASD / 方向键也可用。右侧预留技能键。
- **开始 / 选关**：加载完进标题页 → 选「开始游戏」先选关卡（通关上一关才解锁）→ 选难度 / 诅咒 → 问是否教程 → 开打。第一关 20 回合共 273 只，怪随回合变强（R20 生命 ×4.04 / 伤 ×2.90 / 速 ×1.67），清完通关、生命归零倒下。
- **存档**：每回合自动落档；局内「存档退出」回主菜单；主菜单「读取存档」列中途退出的局（按退出时间排序）；彻底打完自动清档。调试局（`?debug=1`）默认不落档，要落加 `&keepsave=1`。
- **对话读秒**：主线与奇遇每拍一两百字，回话按钮先锁 3s 才亮（个别事件可在数据里写 `readDelay:0` 单独关掉）。
- **永久选择提示**：篝火与永夜火种写进整个存档、不可撤销，首次各弹一次告知 + 页面常驻警示条。
- **礼包兑换**：主菜单输码换夜行骨币（纯前端、不用服务器）。A 类 300 / B 类 100 / **推荐礼包 100 ×10** / **宣传礼包 300 ×10** 共 40 码，一码一机一次；码表只存哈希，明文在 `gift-codes.local.md` 与 `兑换码大全.txt`（gitignore，别提交）。换浏览器/清缓存/换设备 = 记录清零，同码可再用。
- **属性页**：3D 奶蛙展台，按住拖动旋转、松手回正，定时蹦跳拍掌；按 生存/近战/元素/局外 列 14 项（算上篝火与火种，被加成的行标「基础 X」）。
- **音效包**：默认 32 个 CC0 素材；打通第一关后可换 4 段奶蛙叫声替换 8 个位置（拍中/暴击/受伤/怪死/自爆/清回合/通关/倒下），设置里随时切回。
- **每日签到**：以周为大单位 —— 周一 00:00 开新的一周，每天签到 +20 骨币，一周内累计 3 天 +100、6 天 +200（不要求连续，断签不清零；跨周清零）。公告关掉后自动接一次（今天签过就不再弹），主菜单「今日挑战」那排有常驻入口，没签的那天按钮上带红点。
- **公告 / 宣传有礼**：进主界面自动弹公告（提建议/报 bug 发码 + QQ「落花雨 3829845261」+ 网址，均一键复制；勾「今日不再」当天不弹）；关掉公告后接一记「宣传有礼」艺术字特效 → 展开正文（推荐朋友每人 100 / 视频动态 300 / 赞评藏各 5 骨币，联系本人，11 月 30 日统一结算）。主菜单第三排「📢 公告」、第五排「🎁 宣传有礼」随时强制回看。
- **教程**：四步新手教程（移动/攻击/属性/背包）；拿新武器自动弹武器教程（每种只教一次，可跳过，技能栏会整栏上移让开卡片）。
- **自动近战 / 范围环**：范围内自动出手（频率 = 属性 attackSpeed）；脚下青环 = 攻击范围。骷髅也都画自己的圈：小兵暖橙自爆接触圈、战士红近战圈。
- **三选一成长**：每回合清空后暂停弹三张卡（进攻/生存/机动 28 项 + 武器系 10 项），显示原值→选后值，带五档品质（普通/稀有/精良/史诗/传说，是抽签权重而非装饰）；**幸运**只放宽高档。面板打开时世界冻结。
- **随机事件 · 夜行奇遇**：112 个事件、355+ 选项，回合结束抽 1 个（同事件 3 回合不重复），效果落下一回合；带 `cost`/`roll`/`chain`/`permanent`。`民心`(0~100，开局 50) 只影响商店价 0.75~1.25×、金币掉落 ±8%、部分事件出现条件。
- **金币 / 商店**：打死怪概率掉金币（落地 3 秒入账，进攻击范围自动拾取）；每 3 回合弹商店随机摆 4 件（药水/属性/武器/武器属性/法器），同一件一次进店只买一件（买完售罄）。
- **装备**：弩炮台（上限 3，自主索敌）、地刺/霜环（各 3 级范围法器）、金钟罩（每 15s 护体 3s 无敌，多层减周期）；背包（B 键，药水入包再喝）。
- **元素剑 / 环剑**：6 种元素剑（铁/毒/冰/雷/血——冰剑命中直接冰冻、雷剑连锁全场）；环剑 3 把环绕、整环补满、数量无上限；**万剑齐发**（技能键第 1 格，辐射 n=拥有数，6s CD，不影响环上剑）。
- **后续关卡**：二关「骨塔庭院」（三巫师各一技 + 双主题）、三关「焦土钟楼」（冲锋蛮牛/盾斧兽人/孢生菇 + 震钟/棘甲/震剑）、四关「雾堤服务区」（雾鬼隐身无敌/雾猎狼落点跳劈/缝补小巫群奶 + 暖炉），各 20 回合、难度递增。
- **局外成长**：篝火 9 簇无限级火种（每局结算发骨币，越点越贵）；**局外商店·宝箱**（花骨币买木匣 30 / 银匣 100 / 金匣 280，开启直接盲抽一次永久属性变化，诅咒率 35%/18%/7% 中了必给负面；银、金还能开出永久法器与技能CD缩短），永久效果每局开局自动注入；永夜火种 16 张永久卡（本关首通发 3 次三选一）；夜行诅咒 6 条 debuff 换骨币倍率（加法叠加最高 ×2.30）。
- **设置 / 相机**：音量分离/画质/摇杆/抖屏/重置进度；相机死区跟随 + 速度感视野（可关）防晕。
- **帧率自适应**：战斗中连续 2 秒低于 40 帧就自动往下压一档（像素比 → 关阴影 → 更低像素比），稳在 52 帧以上 5 秒再逐级升回你选的那档；全程不写存档，设置里那个值始终是你选的。
- **管理员模式**：设置输密码开启，金币/骨币 ∞ + 跳过/选回合（调试用，不落盘、退出还原）。
- **主线《笑不出来的那一夜》**：18 夜约 2.3 万字，一夜对应一关，三印记抉择（笑声/名字/记忆）决定四结局；主菜单「夜行记忆」可重读全部。

## 运行

浏览器不允许 `file://` 下的 ES Module 与 fetch，不能双击 index.html，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到任何静态托管（GitHub Pages / Netlify / Nginx）都是「整个仓库根目录当站点根」，无需构建。
