# 蛙步 · 夜行（naiwa-rouge）

一个用 Three.js 做的**幸存者类肉鸽游戏**原型。角色是「奶蛙」，来自同作者的音游《蛙步》。纯静态站点（无构建、无 CDN、零依赖，Three.js r160 本地内置），GitHub Pages 发布，手机浏览器兼容是硬约束（不用 importmap / 顶层 await）。

在线试玩：<https://luohuayu-design.github.io/naiwa-rouge/>

当前完成第 67 块（**v=78**）：标题页 + 新手教程 + 3D 角色 + 浮动摇杆 + 主角/武器两套独立属性 + 20 回合关卡（**6 关**）+ 升级成长（28 卡五档品质）+ 武器系统（环剑 + 6 种元素剑 + 万剑齐发 / 箭雨 / 回血）+ 金币/商店 + 随机事件（**131 个**，含主线番外 10 条，对话普遍 100~180 字）+ 音效与 BGM + 图鉴（**15 只怪**）/成就（**41 条**）/战绩/难度 + 篝火局外成长 + 局外商店·宝箱 + 永夜火种 + 夜行诅咒 + 今日挑战/种子 + 礼包兑换 + 公告/宣传有礼 + 每日签到 + 主线剧情《笑不出来的那一夜》+ 攻略面板 + 管理员模式。

**回合事件一览**见 [`关卡事件表.txt`](关卡事件表.txt)（由脚本从代码生成，含升级概率 / 商店价目 / 元素剑图鉴 / 随机事件表）。

## 玩法

- **场景 / 移动**：深夜草地圆形竞技场，可走半径随关卡 15~20（撞边沿切向滑走）。左半屏按住拖动出浮动摇杆；WASD / 方向键也可用。右侧预留技能键。
- **开始 / 选关**：加载完进标题页 → 选「开始游戏」先选关卡（通关上一关才解锁）→ 选难度 / 诅咒 → 问是否教程 → 开打。第一关 20 回合共 273 只，怪随回合变强（R20 生命 ×4.04 / 伤 ×2.90 / 速 ×1.67），清完通关、生命归零倒下。
- **存档**：每回合自动落档；局内「存档退出」回主菜单；主菜单「读取存档」列中途退出的局（按退出时间排序）；彻底打完自动清档。调试局（`?debug=1`）默认不落档，要落加 `&keepsave=1`。
- **对话读秒**：主线与奇遇每拍一两百字，回话按钮先锁 3s 才亮（个别事件可在数据里写 `readDelay:0` 单独关掉）。
- **永久选择提示**：篝火与永夜火种写进整个存档、不可撤销，首次各弹一次告知 + 页面常驻警示条。
- **礼包兑换**：主菜单输码换夜行骨币（纯前端、不用服务器）。A 类 300 / B 类 100 / **推荐礼包 100 ×10** / **宣传礼包 300 ×10** 共 40 码，一码一机一次；码表只存哈希，明文在 `gift-codes.local.md` 与 `兑换码大全.txt`（gitignore，别提交）。换浏览器/清缓存/换设备 = 记录清零，同码可再用。
- **属性页**：3D 奶蛙展台，按住拖动旋转、松手回正，定时蹦跳拍掌；按 生存/近战/元素/局外 列 14 项（算上篝火与火种，被加成的行标「基础 X」）。
- **音效包**：默认 32 个 CC0 素材；打通第一关后可换 4 段奶蛙叫声替换 8 个位置（拍中/暴击/受伤/怪死/自爆/清回合/通关/倒下），设置里随时切回。
- **每日签到**：以周为大单位 —— 周一 00:00 开新的一周，每天签到 +20 骨币，一周内累计 3 天 +100、6 天 +200（不要求连续，断签不清零；跨周清零）。公告关掉后自动接一次（今天签过就不再弹），主菜单「今日挑战」那排有常驻入口，没签的那天按钮上带红点。
- **公告 / 宣传有礼**：进主界面自动弹公告（提建议/报 bug 发码 + QQ「落花雨 3829845261」+ 网址，均一键复制；勾「今日不再」当天不弹）；关掉公告后接一记「宣传有礼」艺术字特效 → 展开正文（推荐朋友每人 100 / 视频动态 300 / 赞评藏各 5 骨币，联系本人，11 月 30 日统一结算）。主菜单第三排「📢 公告」、第五排「🎁 宣传有礼」随时强制回看。
- **教程**：**八步**新手教程（走路 → 判定环 → 打第一只 → 升级三选一 → 属性面板 → 技能栏 / CD 读秒 → 背包 → 开局），第 2 步专门讲「脚下这圈光就是你的攻击范围，走位是把怪带进圈里」；拿新武器自动弹武器教程（每种只教一次，可跳过，技能栏会整栏上移让开卡片）。另外两种「**一次性提示卡**」（第 65 块）也走同一套卡片外观：拿到回血技能后第一次进关教你那个绿十字、第一次被擦名者读条教你头顶那条百分比 —— 都是**世界完全暂停**、只弹一次、写进本机档案。
- **自动近战 / 范围环**：范围内自动出手（频率 = 属性 attackSpeed）；脚下青环 = 攻击范围。骷髅也都画自己的圈：小兵暖橙自爆接触圈、战士红近战圈。
- **三选一成长**：每回合清空后暂停弹三张卡（进攻/生存/机动 28 项 + 武器系 10 项），显示原值→选后值，带五档品质（普通/稀有/精良/史诗/传说，是抽签权重而非装饰）；**幸运**只放宽高档。剑系 9 张（剑伤害 / 暴击 / 击杀吸剑 / 转速 / 锻剑 / 淬毒 / 严寒 / 导电 / 回春）第 64 块整体约**翻倍**，例如剑伤害 +30%→**+60%**、淬毒 +0.05→**+0.12**。面板打开时世界冻结。
- **随机事件 · 夜行奇遇**：**131 个事件**（99 随机 + **10 条主线番外** + 13 连锁后续 + 9 民心专属）、305 个可选项，回合结束抽 1 个（同事件 3 回合不重复），效果落下一回合；带 `cost`/`roll`/`chain`/`permanent`。`民心`(0~120，开局 50) 影响商店价 0.65~1.25×、金币掉落 ±8%、部分事件出现条件；**跨档位会触发专属事件**（涨到新档抽良性池 5 条、跌到新档抽恶性池 4 条，同一档一局只来一次，见 `js/repEvents.js`）。**播放时机（第 67 块，用户定案）**：就在**这一回合**的结算链里 —— 随机事件 → 三选一（这回合该有的话）→ 民心事件 → 商店；这回合没有三选一的，随机事件一关就立刻弹。原来它排在下一回合的奇遇时段、还让位给主线，玩家选完事件得再打一整回合才看到，体感就是「民心升档根本没弹」。关底也照播（选完三选一 → 民心事件 → 结算）。
- **金币 / 商店**：打死怪概率掉金币（落地 3 秒入账，进攻击范围自动拾取）；每 3 回合弹商店随机摆 4 件（药水/属性/武器/武器属性/法器），同一件一次进店只买一件（买完售罄）。
- **装备**：弩炮台（上限 3，自主索敌）、地刺/霜环（各 3 级范围法器）、金钟罩（每 15s 护体 3s 无敌，多层减周期）；背包（B 键，药水入包再喝）。
- **元素剑 / 环剑**：6 种元素剑（铁/毒/冰/雷/血/震）——**除铁剑外全是群体效果**：毒/冰/血/震波及命中点 3.5 格内一圈（冰直接冻 1.6 秒、毒 0.15/秒、血按一圈总伤害回血、震 35% 击退打断），雷剑唯一全场连锁（每道 45%）；波及半径与溅射比例（50%）都在武器属性页可升级；环剑 3 把环绕、整环补满、数量无上限；**万剑齐发**（技能键第 1 格，辐射 n=拥有数，6s CD，不影响环上剑）、冷却倒计时精确到两位小数、**箭雨**（第 2 格，最近一堆怪头顶落箭）、**回血**（第 3 格，第 4 关通关后永久解锁，瞬回 5 点、25s CD、满血不掉 CD；键面是**绿色十字 + 外圈充能环**，第一次进带着它的关卡会弹一张卡教怎么用）。
- **技能只看「解锁」不看「第几关」**（第 65 块）：环剑 / 箭雨 / 回血只要永久解锁过，**任何关卡开局都直接带着**——回头重打第一关，第 5 回合那次「首次得剑」的仪式跳过，开头就有 3 把剑和两个技能键。**新手教程期间技能栏也是亮的**（第 66 块）：八步教程有一讲就是讲右下角技能栏，原来那一刻整栏是隐藏的（开局初始化要等教程结束才跑），等于对着空气讲。现在教程入场就把「解锁过的技能」静默放上去 —— 老玩家重打第一关，讲技能栏那一刻三格都在。
- **箭雨教程不会再卡死**（第 66 块）：武器教程最后一步要求「现在就按一次试试」，但教程期间波次是停的、拿武器又刚好在回合结算之后 —— 场上一只怪都没有，而箭雨在空地按不动（刻意设计，不让人白扔 8 秒 CD）。于是那一步永远等不到箭雨落地。现在这一步会**自动放两只靶子**，打完没按就再补。教程之外空地按箭雨，奶蛙头顶会冒一句「附近没有怪」，不再是静默失败。
- **点不动的两个真 bug 都修了**（第 66 块）：① 收起的教程卡只是 `opacity:0`，里面那个「知道了」按钮仍 `pointer-events:auto`，一块 398×39 的**隐形按钮正好压在屏幕正中**——随机事件的选项、三选一中间那张卡，点上去有三分之一落空，手感就是「很迟钝」。现在卡片收起后 `visibility:hidden`，连命中测试都不参加；卡片里的按钮也统一成「只有卡片亮着才吃点击」。② 箭雨的 8 秒冷却原来会**跨局残留**（重开一局开局就是灰的），现在每局从 0 起。
- **属性面板**：三页签（主角 / 武器 / **技能**）——武器页 12 项环剑属性，技能页把三个技能连同 **CD 时长 / 当前状态（就绪 / 冷却中·还剩 x.xx 秒 / 满血 / 未解锁 + 解锁条件）** 全列出来，箭雨没解锁也查得到。
- **攻略面板**：战败面板「温馨提示」上多了「查看攻略」；手风琴三组（武器 / 属性 / 技能），每条讲「它到底是什么 → 什么时候最强 → 什么时候别指望它」（例：雷剑怪越多越强、万剑齐发留到被围的时候），正文里的 `**重点**` 会渲染成加粗。
- **后续关卡**（每关 20 回合，难度递增）：二关「骨塔庭院」（三巫师各一技 + 双主题）、三关「焦土钟楼」（冲锋蛮牛/盾斧兽人/孢生菇 + 震钟/棘甲/震剑）、四关「雾堤服务区」（雾鬼隐身无敌/雾猎狼落点跳劈/缝补小巫群奶 + 暖炉）、五关「草甸路口」（**四向路口**：怪只从东南西北四条路上来，可以提前站位；新怪擦名者偷你环上的剑、得手就跑 + 路口灯反隐）、六关「骨塔机房」（**漏电地板**周期通电，站上去每 0.6 秒掉 1 血 + 重启体死后 4 秒半血重启、最多 2 次 + 绝缘斗篷以毒攻毒）。剧情 s05 / s06 分别绑在五、六关第 2 回合。
- **五、六关难度**（第 65 块按实测反馈抬的）：整关乘数 **伤害 ×1.35 / 血量 ×1.15**（写在关卡表 `scale.dmgMul / hpMul`，只抬这两关，前四关一点没动）。
- **擦名者的读条看得见了**（第 65 块）：它在远处站定读条时，**奶蛙头顶浮一条紫色百分比**（越接近 100% 越危险，过 65% 变粉并脉动催你），第一次见到会把世界冻住弹一张卡解释这条百分比是什么、怎么破（冲过去打断）。
- **雾鬼显隐差别拉大**（第 65 块）：隐身时透明度压到 **0.05**（几乎只剩轮廓），显形时**自发光从 0.3 拉到 2.2** —— 在浓雾里亮起来比「变不透明」更容易被余光抓住。
- **缝补小巫的奶有了存在感**（第 65 块）：被治的怪身上会**连冒 1.4 秒绿加号**（每 0.16 秒一个，一边往上浮一边变大），隔半个场地也看得出哪只在回血；范围 8.0 格，但不再画那个巨大的判定圈。
- **局外成长**：篝火 9 簇无限级火种（每局结算发骨币，越点越贵）；**局外商店·宝箱**（花骨币买木匣 30 / 银匣 100 / 金匣 280，开启直接盲抽一次永久属性变化，诅咒率 35%/18%/7% 中了必给负面；银、金还能开出永久法器与技能CD缩短），永久效果每局开局自动注入；永夜火种 16 张永久卡（本关首通发 3 次三选一）；夜行诅咒 6 条 debuff 换骨币倍率（加法叠加最高 ×2.30）。
- **设置 / 相机**：音量分离/画质/摇杆/抖屏/重置进度；相机死区跟随 + 速度感视野（可关）防晕。
- **帧率自适应**：战斗中连续 2 秒低于 40 帧就自动往下压一档（像素比 → 关阴影 → 更低像素比），稳在 52 帧以上 5 秒再逐级升回你选的那档；全程不写存档，设置里那个值始终是你选的。
- **管理员模式**：设置输密码开启，金币/骨币 ∞ + 跳过/选回合（调试用，不落盘、退出还原）。
- **主线《笑不出来的那一夜》**：18 夜约 2.3 万字，一夜对应一关，三印记抉择（笑声/名字/记忆）决定四结局；主菜单「夜行记忆」可重读全部。

## 运行

浏览器不允许 `file://` 下的 ES Module 与 fetch，不能双击 index.html，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到任何静态托管（GitHub Pages / Netlify / Nginx）都是「整个仓库根目录当站点根」，无需构建。
