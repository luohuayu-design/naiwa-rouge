一个用 Three.js 做的**幸存者类肉鸽游戏**原型。角色是「奶蛙」，来自同作者的音游《蛙步》。

## 玩法

- 深夜草地圆形竞技场，可走半径 15（边界是发光草圈 + 石头圈，撞边会沿切向滑走，穿不出去）。
- **移动**：左半屏任意位置按住拖动，浮动摇杆就在落点出现；键盘 WASD / 方向键同样可用（斜向已归一化）。右侧 42% 屏幕预留给后续技能键。
- **开始界面**：加载完成后进入标题页（大标题「奶蛙夜行」+「开始游戏」按钮）；点开始后询问「先来一遍新手教程？」——**开始教程**（三步互动引导）或**跳过**直接开打。
- **主页面 · 开始游戏 / 我的记录**（第 14 块）：进站先到主页面（大标题「奶蛙夜行」），两个入口 —— **「开始游戏」先弹关卡选择**（关卡做成清单 `LEVELS`，每张卡写回合数/怪数/最佳记录；第 1 关永久解锁，后面的关**通关上一关才解锁**，未解锁的显示 🔒 点了没反应；选中关卡后才进「新手教程？」询问）；**「我的记录」**分关卡展示**通关次数 / 最快通关 / 最高击杀 / 最远回合**四格（存 `localStorage` 键 `naiwa_rouge_records_v1`，本机保存；结算面板一弹出就落账，没打过显示空态文案）。加新关 = `main.js` 的 `LEVELS` 加一条 + `wave.js` 出一个 `createLevelN`。
- **新手教程**（四步、可随时跳过）：① 移动 —— 真的拖动摇杆（或 WASD）跑 2.5 格才过；② 攻击 —— 场上刷一只 0 伤害的教程靶子，靠自动攻击拍死它；③ 属性 —— 打开再关掉属性面板；④ **背包与按钮（第 16 块）** —— 点右下角背包按钮（或 B）打开再关掉，顺带介绍喇叭声音开关。教程期间不推进回合波次；怪物模型加载失败时自动跳过教程，不会卡人。
- **武器用法教程**（第 15 块）：**每次拿到没见过的新武器**自动在底部弹一张小卡片教这件武器怎么用，不挡操作、随时可「跳过教程」——**环剑**三步（剑自己转 / 每 3 秒补剑 / **万剑齐发要真的按一次 1 或点技能按钮**才算学会）；商店买到的**新种类元素剑**各一步讲效果与用法（毒/冰/雷/血），离店后才弹（不盖在货架上）。每种武器只教一次（`localStorage` 键 `naiwa_rouge_wtut_v1`，跳过也算知道了）；结算时硬收不留到下一局。加新武器的教程 = `main.js` 的 `WEAPON_TUT` 表补一条。
- **自动近战**：攻击范围（2.1）内有怪就自动出手，攻击频率是属性 `attackSpeed`（初始每秒 1.2 次，升级可加快），出手瞬间转向最近的目标并播放「抬手 → 拍下」的攻击动作（0.52 秒，大幅度后仰蓄力 + 转腰甩臂 + 前扑，叠加在走/跑动画之上）；没有目标不空挥。挥击有冲击环特效。走路摆臂幅度加大（0.86 rad，躯干反向扭转配合），跑起来一眼能看出在用力。
- **范围环**：主角脚下有一圈青色光环，半径就是当前攻击范围（升级加范围会立刻变大）——站到环边就正好够不着。骷髅也都画着自己的圈：小兵是暖橙色的自爆接触圈（主角半径 + 接触距离），战士是红色的近战圈（1.55），看到环压过来就该退。
- **第一关 · 荒草地**：**20 个回合**，共 163 只小兵 + 67 只战士 + 26 只投手 + 17 只弓手（**273 只**，第 13 块从 15 回合扩来，第 12 回合起投手、第 12 回合起弓手混编）。每回合必须清完才进下一回合（没有超时跳过）。**怪物随回合变强**：第 20 回合生命 ×4.04、伤害 ×2.90、速度 ×1.67。清完全部 → 通关；生命归零 → 倒下。结算面板显示用时/击杀/回合/升级次数/剩余生命/攻击力/金币/**骨币收入**（骨币行单独一条暖色，见「篝火 · 夜行骨币」）。
- **三选一升级**：第 **1 / 2 / 3 / 4 / 5 / 8 / 10 / 12 / 15 / 17 / 19 / 20** 回合清空后暂停，弹出三张卡（**进攻 / 生存 / 机动**三系各抽一张，共 **28 项**：**18 项主角**（含「好运」「福星」「双拍」与第 13 块的「金钟罩」）+ 拿到环剑后追加的 **10 项武器系**；**剑系只加武器自己的数值，主角属性一动不动**）。卡片上直接显示受影响属性的「原值 → 选后值」（用 `stats.preview` 预演，与实际生效完全一致）。**每个回合的概率都不同**：每项权重 = `w0 + gw × (回合-1)` 线性变化，前期攻击力/生命上限更常见，后期暴击/吸血/剑系抬升、弱项降权；同一系内按权重瓜分 100%。**每张卡还带品质**（普通/稀有/精良/史诗/传说，见下条），品质是抽签上的又一层权重，页脚实时写着「幸运 X · 精良及以上 Y%」。选哪张立即生效，第 20 回合的最后一格选完直接通关。面板打开时世界完全冻结。
- **卡牌品质 · 五档**（第 11 块，`js/rarity.js` 是唯一真相源）：**普通（灰 #9aaba4）→ 稀有（绿 #4fd07a）→ 精良（蓝 #4aa8ff）→ 史诗（金 #f0b93c）→ 传说（红 #f0554e）**。三选一卡片与商店货架**都**带品质：左边 3px 色条 + 名字后的角标（普/稀/精/史/传）+ 内发光，史诗微微发亮，传说有 2.6 秒一次的呼吸动画。品质不是装饰，它是一层**抽签权重**：`实际权重 = 基础权重 × 品质系数（1.00 / 0.92 / 0.72 / 0.40 / 0.22）× (1 + 幸运 × 该档幸运系数)`。分档原则是「**日常在用的卡才是普通**」+「**每个系都要有高有低**」—— 早先试过「先摇品质再挑卡」，结果因为稀有档卡片数量多反而比普通更常见（普通约 0%），已回退成现在这套加权。实测（幸运 0）：第 1 回合 普通 58% / 稀有 25% / 精良 15% / 史诗 0% / 传说 1.6%，第 10 回合 35% / 32% / 30% / 1.8% / 1.6% —— 传说一整晚（8 次三选一）大概见 1~2 张。28 张卡的分布：普通 9、稀有 6、精良 7、史诗 4（剑阵/导电/双拍/金钟罩）、传说 2（福星/不灭）。
- **新属性「幸运」**（第 11 块）：base 0（暴击/吸血那一类，只能用 flat 加），属性面板「经济」组可见，卡片页脚与商店页脚都会显示。**它只放宽高品质那一头**，不会让好卡变少：幸运 3 时「精良及以上」第 1 回合 16% → 23%、第 10 回合 33% → 42%（每点约 +2~3 个百分点）。三个来源：升级卡「好运」+1（稀有）、「福星」+2（传说，附赠 +5% 暴击 +10% 金币掉落）、商店传说货「压胜钱」+1（34 币）；事件（罐里的蟋蟀 / 流星 / 脚下有东西 / 掷骰子的骷髅）也能给 1 点。幸运同时让**商店更容易摆出好货**（摆货也是同一套品质加权）。
- **随机事件 · 夜行奇遇**（第 7 块重做、第 10 块加对话、第 11 块再扩 13 个）：**每回合结束时**抽 1 个事件（同一事件 3 回合内不重复），效果**落在下一回合**——回合开始时不弹了，回合结束的清场间隙里，你先看一段故事，再决定怎么做。事件都是「有个具体的人/东西在跟你说话」（`who` 一栏写着是谁）：路边的乞丐、井底的东西、被绑着的俘虏、断了桥的商队。**第 31 块扩到 99 个随机事件 + 13 个连锁后续 = 112 个事件、355+ 个选项（22 个多轮对话，46 拍）**——新增文本普遍 100~180 字（用户点名要长对话），分 6 条剧情线 + 第 11 块的「**九、运气与口袋**」（13 个）+ 第 12 块的「**十、赌与运气**」（12 个 + 1 条新连锁「瘸腿的狗」）。第 12 块这一批的共同点是**随机性更强**：同一个选项也可能有两种结果（掷骨子 45% 赢 / 三岔口 / 酒坛四选一结果 / 星图 / 镜面池塘三选一），甚至把「随机一项属性大涨」直接丢给你（蛙神像、酒坛）；事件权重也拉开了（0.8~1.3），每局的遭遇顺序更难预测。旧的两类专门产出**跨回合的正面东西**：永久金币掉落率、永久幸运、生命回满、下次商店 8 折。
  - **乞丐线**：施舍 5 币 → 3 回合后捧着野果回来报恩（+12 币 +1 攻击力）；赶走他 → 他吐你一口（下回合每秒 -0.1 生命）。
  - **小偷线**：抓住后放走 / 送他一程 / 送到村里 → 2~3 回合后可能是**夜里摸回来报复**（掉血掉钱）、**提前报信**（下回合怪少一截），也可能**偷偷往你包里塞钱**。
  - **病孩线**：掏钱请郎中 / 只给点草药 / 走开 → 2 回合后孩子好了（民心大涨）或没了（民心大跌 + 阴影）。
  - **商队线**：收过路钱 / 白护送 / 不管 → 2 回合后回头送礼或再不相见。
  - **荒井线**：探头捞钱（50% 得金币 / 50% 掉血）/ 填了它 → 3 回合后井里的东西现身。
  - **俘虏线**：放走 / 逼问 / 杀掉 → 2 回合后他拎着骨刀回来站你这边（或再没出现）。
  选项可能带 `cost`（金币/生命，**不够就点不了**，按钮变灰并写明缺什么）、`roll`（概率分支，直接在提示里写明百分比）、`chain`（埋伏笔）、`permanent`（永久加成，不随回合撤销）。**第 11 块给 `effects` 补了三种新写法**：`permanent: [{ stat, flat, pct }]` 现在既支持按百分比加、也能用 `scope: 'weapon'` 打到武器表上；`healFull` 直接把生命回满；`discount` 让**下一家店**打 8 折（一次性，取更强的那个，进店/关店就清零，与民心价相乘）。单个事件也有纯叙述型的（寒潮、夜风、鼓手、断桥），但都给出可权衡的取舍，不是白送的数值。
- **民心 · 唯一跨回合的东西**（第 7 块新增）：0~100，开局 **50**。选善举涨、选狠手跌——每个选项涨跌多少写在按钮提示里。民心**只影响三件事**，但影响得很实：**商店价格 0.75×~1.25×**（民心高商人主动让价，民心低就往死里宰）、**金币掉落率 ±8%**、**部分事件只在民心很高/很低时才出现**（高民心：村民送礼、篝火夜谈；低民心：夜里有人摸你的钱袋）。跨过 20/40/60/80 档位时会弹一句提示（「村里人见了你会点头了」/「路过的人开始绕着你走」）。左上角金币角标旁多一颗心形角标，实时显示民心。
- **金币**：打死怪**有一定概率**掉一枚（基础 45%，属性 `goldRate`，「财运」升级 +10%），**不需要拾取**——金币弹起、落地后**停 3 秒**（第 12 块从 0.5 秒加长，落地后会原地轻轻浮动）再消失并计入数据（左上角金币角标实时显示）。金币只在商店里花，本局内有效。
- **商店 · 流浪商人的摊子**：每 **3** 回合（第 3/6/9/12/15/18）清空后、三选一之后弹出；**每次只随机摆 4 件**（第 9 块）——同一家店货架固定，关掉下次进来重新抽，抽签会先剔掉「现在买了也没用」的（没环剑时的剑类、炮台满 3 台、法器满级；**药水不再剔**——第 13 块起买药进背包，满血也能囤）；**摆货本身也按品质加权**（第 11 块），幸运越高越容易摆出剑油 / 磨剑石 / 元素剑这类高档货。可以**连买多件不同货**，但**同一件货一次进店只能买一件**（第 25 块改：买完挂「售罄」，下次进店重新上架）。五类货：**药水**（回复 3.0 生命 8 币 / 回满 18 币，**买后进背包**）、**属性加成**（攻击 +1、生命上限 +2、移速 +8%、攻速 +10%、**幸运 +1（压胜钱 34 币，传说）**、**金钟罩符 36 币（传说）**，全部永久）、**武器**（铁剑 20 币 + 4 种元素剑 26~38 币，需先持有环剑）、**武器属性**（剑油 +15% 剑伤害 18 币、磨剑石 +5% 剑暴击 22 币，同样只加剑不加主角）与第 13 块的**召唤物/法器**（**弩炮台 32 币史诗**、**地刺图样 28 币史诗（第 8 回合起上架）**、**霜环图样 30 币史诗（第 11 回合起上架）**）。**价格 = 原价 × 民心系数（0.75~1.25）× 折扣**，事件给的「下次商店 8 折」只对整个下一家店生效。第 20 回合是最后一关，清完直接结算不弹商店。

## 运行

浏览器不允许 `file://` 下的 ES Module 与 fetch，所以**不能双击 index.html**，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到任何静态托管（GitHub Pages / Netlify / Nginx）都是「整个仓库根目录当站点根」，无需构建。

## 技术要点

- **Three.js 固定 r160**，本地内置运行时零外部请求。
- **手机兼容是硬约束**：不用 importmap、不用顶层 await —— iOS 16.4 以下的 Safari、旧版微信/安卓 WebView 不支持 import maps，iOS 15 以下不支持顶层 await，任何一条都会让整个模块解析失败、加载页永远停在 0%。所有 import 都写相对路径（`../lib/three.module.js`），主流程包在 `boot()` 里，index.html 末尾有兜底自检（模块 9 秒没跑起来就在加载页写明原因），GLB 下载进度在拿不到 Content-Length 时按文件大小估算。改加载相关代码时这三件事别回退。
- 奶蛙：单网格无骨骼 → `frog.js` 程序化 7 骨 + 距离蒙皮，腿骨枢轴在胯部；正面朝 +Z。
- 怪物：KayKit 模型自带 41 骨骼蒙皮与动画 → `SkeletonUtils.clone` 克隆实例 + 每只独立 `AnimationMixer`；材质逐实例克隆（受击闪白不串场）。
- **怪物身高标定是坑**：KayKit 模型的几何包围盒 / `boneTransform()` 与实际渲染差得极远，`ENEMY_TYPES` 里的 `sourceHeight` 是原点参照物截图实测值（minion 1.05 / warrior 1.15 / archer 1.10），换模型必须重测（也可用 `applyBoneTransform()` 蒙皮顶点法做相对校验）。`height` 是按 `sourceHeight` 归一后的世界身高，血条/特效都用它。
- **头顶血条**（`enemy.js` 的 `createBar`）：canvas 贴图 Sprite，**必须 `depthTest: false`**（否则俯视相机会被怪自己的头从中间挡住）+ `position.y = height + 0.95`（贴太近会横穿脸部）；`draw(ratio, hp, maxHp)` 顺带把数值画进条里。
- **体型基准**：主角 `frog.js` 的 `RIG.TARGET_H = 2.28`（原始 1.9 × 1.2），怪物 `height` 取 0.8 折（minion 1.14 / warrior 1.38 / archer 1.28）——视觉上主角略高于小兵、矮于战士。
- **回合成长**（`wave.js`）：`rounds` 表驱动（15 回合，含投手列），`roundScale(r)` 给出 hp/damage/speed 倍率；`spawn(type, at, {hpScale, damageScale, speedScale})` 倍率**只落实到实例**，绝不改 `ENEMY_TYPES`。要调强度改 `rounds` 或倍率公式。
- **远程怪 · 骨刀弹道**（`enemy.js`）：投手 AI = 距离 < `keepDistance`(4.2) 后退、> `attackRange`(7.0) 靠近、之间站定拉弓（前摇 0.72 秒，脚下橙色脉冲蓄力圈）→ `throwBone()` 生成共享几何的骨刀 Mesh，直线飞行（速度 5.6、寿命 2.6 秒、出界消失），水平面判定命中主角（半径 0.30 + 主角半径）。骨刀只朝出手瞬间的主角位置飞，不追踪。**第 6 块按反馈全面下调：伤害 2→1、间隔 2.6→3.6 秒、弹速 8.5→5.6、前摇 0.55→0.72**。弹体几何/材质全系统共享一份，移除时只 `scene.remove` 不 dispose。
- **怪群分散**（`enemy.js`）：`spawn` 时 `speedMul = 0.85 + rng×0.30` 落在实例上；`restCd/restT` 驱动随机休息（出手时不歇）；`moveToward` 里把「指向玩家」的方向绕竖轴旋转 `driftAmp × near × sin(t×driftFreq + phase)`——`near = dist/2.5` 让摆幅在贴脸时收小，避免绕圈打不到人。三个参数都在生成时随机，配合碰撞分离实现「不抱团」。
- **环剑**（`weapon.js`）：剑模型 Kenney《Mini Dungeon》（CC0，9KB）；**剑刃必须外扬 35°**——顶视角相机下平躺的剑只剩一条线，根本看不见。**剑身整体放大 1.4 倍**（`SWORD_SCALE`，判定半径同步 0.55→0.77）。**多元素实现**：`protoFor(kind)` 克隆模板后逐网格克隆材质，按 `SWORD_KINDS` 调 color/emissive（自发光 2.2，深夜 + ACES 会吃饱和度）；对象池按元素分池。`owned` 数组记录拥有的剑（按获得顺序），**环上数量 = owned.length（不设上限，第 9 块）**；被消耗的剑按「owned 里有、环上没有」优先恢复。`fire()` 一次射出 **2n 把**：原有 n 把沿各自朝向 + 在每两把之间插入一把（沿用前一把元素）。命中 → `applyKind()`：毒挂 DoT（`enemy.applyDot`，0.5 秒一跳）、冰挂减速（`applySlow`）、雷 `chainTargets` 连锁 + 手绘 Line 电弧（0.22 秒淡出）、血按伤害回血。模型加载失败自动换双盒占位剑。
- **第四种怪 · 红圈落箭**（`enemy.js`，第 12 块）：弓手 AI 与投手同样「keep/靠近/站定」，但出手走 `spawnVolley()` —— 在**主角当下位置**钉一个固定红圈（disc 红雾 + rim 亮环 + tick 收缩细环，缩到底 = 落地），`windup` 1.15 秒后圈消失、7 支箭从 y=6.2 落下（0.3 秒），**落地那一刻**按「主角圆心是否在圈内」结算一次伤害。圈的位置、时间窗口都写在 `volley` 配置里，纯数据可调。模型复用 `skeleton-mage.glb`（9 段动画含 `1H_Ranged_Aiming/Shoot`），程序化弓（Torus 弧 + Line 弦）挂在 `handslotr` 骨骼上：**朝向用「骨骼世界四元数⁻¹ × 模型世界四元数」反解**，不依赖骨骼轴约定；法师帽（`Skeleton_Mage_Hat`）对弓手隐藏。⚠️ GLTFLoader 会把骨骼名里的 `.` 洗掉（`handslot.r` → `handslotr`），找骨骼两个名字都要试。
- **金币**（`gold.js`）：击杀回调里按 `goldRate` 掷骰 → 金币 Mesh（共享几何/材质）弹起自转，**落地 3 秒后**销毁并 `onGold(1)` 入账（第 12 块从 0.5 秒加长；落地后原地轻轻浮动，最后 0.25 秒缩小）。金币不是属性，是本局货币，只在商店花。
- **随机事件**（`events.js` + `main.js`，第 7 块重写、第 10 块加对话）：事件两种形态——**一次抉择** `{ ..., choices[] }` 与**多轮对话** `{ ..., talk[] }`。对话每一拍 = `{ who?, say, replies[] }`，你的回话 `say` 会作为右侧气泡留在记录里，`close` 是对方听完的反应；回话带 `go: n` 就跳到第 n 拍接着聊，不带就进结算。多拍选的效果经 `mergeEffects` **累积成一张账单**（数字相加、mods 相接、level 倍率相乘），聊完一次性落地；金币/生命的代价当场就扣（`resolveRoll` 在选中的那刻摇概率）。`eventChoices(ev)` 把两种形态拉平，文档与测试共用。`effects` 支持 `rep/gold/hp/drain/level/mods/permanent/chain/roll/healFull/discount`：
  - **`cost` 负责扣钱扣血，`effects` 里绝不能再写同名负数**（否则扣两次——这条踩过）。
  - **`mods` 写进 `stats` 时 src 是 `event:<下一回合号>`**，`clearRoundBuffs()` 在下一回合结束时整批撤销（`removeBySource`），两张表都清；`permanent` 用 src `pledge:<回合>`，撤销不会碰它。
  - **`chain`** 往 `laterQueue` 压一条 `{ in, id }`，回合结束时先兑到期的连锁后续（`chainOnly: true` 的事件不参与随机抽取，只能被 `chain` 拉到），再抽本回合的新事件 —— 所以「3 回合后乞丐回来」是准时准点的。
  - **`roll`** 是概率分支（`[{p, effects}]`），`p` 只用来掷骰，**提示文案要自己把百分比写进 `hint`**，玩家看得见概率。
  - **`cond(ctx)`** 拿 `{ rep, gold, hp, round, hasWeapon, ... }` 决定这个事件能不能出现 —— 民心专属事件（`villageGift` rep≥70、`nightTheft` rep≤30）和武器专属事件（`wind` 需要环剑）都靠它。
- **民心**（`main.js`）：`reputation` 0~100、开局 50，不进存档（一局一结算）。三处挂钩：`repPriceMul() = 1 - (rep-50)/200` 夹在 `[0.75, 1.25]`，`priceOf(item)` 取整并保底 1 币；`syncRepBonus()` 用 `removeBySource('rep')` 重挂 `goldRate ±0.08`；`repTier()/repTierAt()` 分 5 档，`addRep()` 跨档时弹 toast。改民心只走 `addRep()`，别直接赋值（否则金币加成不刷新）。
- **回合链**（第 7 块顺序）：回合清空 → `clearRoundBuffs()` → （第 5 回合武器卡）→ **事件**（先兑到期连锁，再抽新事件）→ 三选一 → 商店（3/6/9/12/15/18）→ 下一回合。每个面板关闭时通过 `after` 回调接续下一段，全部关闭才恢复 `playing`；第 20 回合（最后一关）不弹事件与商店。**`handleRoundClear` 只允许存在一份**（同名 function 重复声明会静默覆盖，商店不弹的 bug 就是这么来的）。
- **事件结果页**：选完不直接关，先显示角色的回应（`say`）+ 结算行（`effectLines`，统一说「下回合」、永久项标「（永久）」），玩家点「知道了」才收。`effectLines` 是事件卡与结果页共用的唯一文案来源，别在别处手写效果描述。
- **属性分两块表**（第 6 块）：`stats.js` 泛化成 `createStats(defs)`，主角 `STAT_DEFS`（**14 项**，第 11 块加「幸运」、第 12 块加「同时命中」、第 13 块加「金钟罩」）与武器 `WEAPON_STAT_DEFS`（11 项）各造一个实例，公式与减伤完全同一套。剑击伤害走 `rollSwordDamage(wstats)`，**不读主角任何数值**。升级/商店/事件里 `scope:'weapon'` 的条目落到 `wstats`，其余落到主角；事件 buff 撤销时两张表都要清。属性面板按 defs 的 `group` 字段分组、按页签渲染。
- **召唤物/法器/护体（第 13 块）**：`turret.js` 的 `createTurretSystem` 管所有炮台（列表 + 弩箭对象池，弹道判定与骨刀共用思路但共享几何独立一份）；`relics.js` 的 `RELIC_DEFS` 表驱动两件法器（伤害/半径/间隔全在表里），dot 走静默结算不刷飘字、霜环减速走 `enemy.applySlow`；金钟罩是 `main.js` 的 `aegisCycle`（层数只减周期，`Math.max(10, 15 - (层-1)×1.5)`），护体窗口在 `hurtPlayer` 入口最先判定；背包 `BAG_ITEMS` 表驱动、`bagAdd/useBagItem/setBag` 三个入口，商店买药走 `bagAdd`。**新物品类型进背包 = 往 `BAG_ITEMS` 加一条**，面板与角标自动跟上。
- **升级三选一**（`upgrade.js`）：基础值为 0 的属性（暴击率/吸血/剑暴击率/**幸运**）**必须用 `flat` 加成**——百分比公式是 `(base+flat)×(1+pct)`，base=0 时 pct 完全无效。加成经 `addMod` 带 `src` 标识，可整批撤销。武器系升级带 `needsWeapon` 标记，没拿到环剑前权重为 0。每项权重 `w0 + gw × (回合-1)`，`chanceTable(round)` 能算出任意回合各选项的概率（`关卡事件表.txt` 就是它生成的）。
- **品质 = 抽签上的一层权重**（`rarity.js`，第 11 块）：`池里每张卡的实际权重 = (w0 + gw×(回合-1)) × RARITIES[rarity].mul × (1 + 幸运 × RARITIES[rarity].luck)`，`pickFromPool` 按 `w × rw` 加权不放回抽。**曾经试过「先摇品质、再在那一档里挑卡」，结果是稀有档因为卡片数量多反而比普通更常见（普通约 0%）**——同一档里的卡片数量会污染概率，所以必须加权到卡上而不是先摇档。`rarityOdds(round, {luck})` 给页脚「精良及以上 Y%」用（内部要把 `{up,w}` 先映射成 `{rarity,w}` 再交给 `oddsOf`，否则全算成普通档）；商店 `rollShopItems(rng, {luck})` 用的是同一套加权（商品 `rarity` 写在 `SHOP_ITEMS` 里）。加新卡/新货**必须写 `rarity`**，漏写会当普通处理。
- **幸运只放宽高档**：`luck` 的系数是各档独立的（普通 0 → 传说 0.55），所以幸运不会改变低档的相对比例太多，但会让「精良及以上」明显变多（每点约 +2~3 个百分点）。
- **开局状态机**（`main.js`）：`title → tutorial | playing → event | upgrade | weapon | shop → over`。`?debug=1` 自动跳过标题页与教程**并且跳过随机事件卡与商店自动弹出**（测试需要确定性开局；手动 `__game.shop.open()` / `__game.event.trigger(id)` 仍可测）；`?debug=1&story=1` 保留叙事；`?debug=1&title=1` 保留标题页。教程第 2 步的靶子 0 伤害 1 血，`damageScale` 会被四舍五入回 1，所以要手动 `tutDummy.damage = 0`。
- **音频引擎**（`audio.js`，第 8 块）：音效走 WebAudio（`decodeAudioData` 解码一次，之后每次 `AudioBufferSourceNode`，天然并发）；BGM 走两个 `HTMLAudioElement` 轮流当 A/B 轨做交叉淡化（素材本身已交叉淡化成无缝循环，`loop` 直接用）。三条铁律：① `AudioContext` / `Audio.play()` 必须在**用户手势**里解锁（`unlock()` 挂在全局 `pointerdown`，解锁前请求的曲子记在 `wantBgm`，解锁后补播）；② 音效在解锁后才 `fetch`+解码，开局加载段零音频请求；③ 同名音效 25ms 内不重复触发、全场最多 24 路。BGM 切换由 `main.js` 的 `syncAudio()` 每帧比一次状态（title/panel/battle/paused/over）驱动，面板切换曲目、属性面板内暂停只压低（×0.34）不换曲。
- 距离与索敌在 `stats.js`：`distance2D`（只算水平面）/ `inRange2D` / `nearestInRange`（射程内最近、自动跳过死者）；`stats.findTarget()` 用当前攻击范围。
- **范围环**（`rangeRing.js`）所有环共用一张 canvas 环贴图 + 一块半径 1 的平面（`scale` 当半径），加色混合、贴地 y≈0.03、`depthWrite:false`，不和地面抢深度。主角环挂在场景上跟 `pos` 走 —— 角色模型走路/倒地会让 `root.y` 起伏，挂身上环会浮起来；怪物环挂在各自 root 下，死亡缩小/下沉时自然一起消失。要改粗细/亮度就改贴图的渐变 stop 与 `opacity`。
- 主角受击有 **0.55 秒无敌帧** + 屏幕红闪 + 相机震动，防止被多只小兵同帧秒杀。
- 属性加成模型：`(基础值 + Σ加法) × (1 + Σ百分比)`，`stats.addMod({stat, flat|pct, src})` / `removeBySource(src)`。
