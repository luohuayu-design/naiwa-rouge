# 蛙步 · 夜行（naiwa-rouge）

一个用 Three.js 做的**幸存者类肉鸽游戏**原型。角色是「奶蛙」，来自同作者的音游《蛙步》。
当前完成第 6 块：**标题页 + 新手教程 + 3D 角色 + 浮动摇杆 + 属性系统（主角/武器两套独立数值） + 15 回合关卡（含远程怪「骷髅投手」） + 升级成长 + 武器系统 + 金币/商店 + 元素剑 + 随机事件 + 怪群分散**。

**回合事件一览**见 [`关卡事件表.txt`](关卡事件表.txt)（由脚本从代码生成，含升级概率明细 / 商店价目表 / 元素剑图鉴 / 随机事件表）。

在线试玩：<https://luohuayu-design.github.io/naiwa-rouge/>

## 玩法

- 深夜草地圆形竞技场，可走半径 15（边界是发光草圈 + 石头圈，撞边会沿切向滑走，穿不出去）。
- **移动**：左半屏任意位置按住拖动，浮动摇杆就在落点出现；键盘 WASD / 方向键同样可用（斜向已归一化）。右侧 42% 屏幕预留给后续技能键。
- **开始界面**：加载完成后进入标题页（大标题「奶蛙夜行」+「开始游戏」按钮）；点开始后询问「先来一遍新手教程？」——**开始教程**（三步互动引导）或**跳过**直接开打。
- **新手教程**（三步、可随时跳过）：① 移动 —— 真的拖动摇杆（或 WASD）跑 2.5 格才过；② 攻击 —— 场上刷一只 0 伤害的教程靶子，靠自动攻击拍死它；③ 属性 —— 打开再关掉属性面板。教程期间不推进回合波次；怪物模型加载失败时自动跳过教程，不会卡人。
- **自动近战**：攻击范围（2.1）内有怪就自动出手，攻击频率是属性 `attackSpeed`（初始每秒 1.2 次，升级可加快），出手瞬间转向最近的目标并播放「抬手 → 拍下」的攻击动作（0.52 秒，大幅度后仰蓄力 + 转腰甩臂 + 前扑，叠加在走/跑动画之上）；没有目标不空挥。挥击有冲击环特效。走路摆臂幅度加大（0.86 rad，躯干反向扭转配合），跑起来一眼能看出在用力。
- **范围环**：主角脚下有一圈青色光环，半径就是当前攻击范围（升级加范围会立刻变大）——站到环边就正好够不着。骷髅也都画着自己的圈：小兵是暖橙色的自爆接触圈（主角半径 + 接触距离），战士是红色的近战圈（1.55），看到环压过来就该退。
- **第一关 · 荒草地**：**15 个回合**，共 109 只小兵 + 40 只战士 + 10 只投手（159 只）。每回合必须清完才进下一回合（没有超时跳过）。**怪物随回合变强**：第 15 回合生命 ×3.24、伤害 ×2.40、速度 ×1.49（小兵第 5 回合起 2 刀一只、第 15 回合 3 血，战士 3 → 10 血、伤害 1 → 2；投手骨刀 1 → 2；主角 4.4 移速始终跑得过最快的怪）。清完全部 → 通关；生命归零 → 倒下。结算面板显示用时/击杀/回合/升级次数/剩余生命/攻击力。
- **三选一升级**：第 **1 / 2 / 3 / 4 / 5 / 8 / 10 / 12 / 15** 回合清空后暂停，弹出三张卡（**进攻 / 生存 / 机动**三系各抽一张，共 23 项；拿到环剑后追加 **10 项武器系**：剑刃、剑锋、淬锋、剑阵、疾轮、锻造 + 淬毒、严寒、导电、活血，另有「财运」提升金币掉落率；**剑系只加武器自己的数值，主角属性一动不动**）。卡片上直接显示受影响属性的「原值 → 选后值」（用 `stats.preview` 预演，与实际生效完全一致）。**每个回合的概率都不同**：每项权重 = `w0 + gw × (回合-1)` 线性变化，前期攻击力/生命上限更常见，后期暴击/吸血/剑系抬升、弱项降权；同一系内按权重瓜分 100%。选哪张立即生效，第 15 回合的最后一格选完直接通关。面板打开时世界完全冻结。
- **随机事件 · 夜行奇遇**：**每回合开始前**抽 1 个事件（同一事件 3 回合内不重复），有好事有坏事，效果**只生效一回合**（回合开始前自动清掉上一回合的临时加成）。有的是纯叙述（寒潮 -10% 移速、骷髅喝多了下回合怪变少），有的要做选择：路边乞丐（施舍 5 金币 → **3 回合后回来报恩** +12 金币 +1 攻击力；不施舍 → 朝你吐痰，本回合每秒 -0.1 生命）、两瓶可疑药水（红/蓝/不喝，各藏概率分支）、荒废老井（探头 50% 捞 15 金币 / 50% 掉 2 血）、迷路的小骷髅（指路下回合怪 -20% / 拍碎得 3 金币）。共 14 个事件，写在 `events.js`，后续素材到位继续扩。
- **金币**：打死怪**有一定概率**掉一枚（基础 45%，属性 `goldRate`，「财运」升级 +10%），**不需要拾取**——金币弹起、0.5 秒后自动消失并计入数据（左上角金币角标实时显示）。金币只在商店里花，本局内有效。
- **商店 · 流浪商人的摊子**：每 **3** 回合（第 3/6/9/12）清空后、三选一之后弹出；可以**连买多件**。三类货：**药水**（回复 3.0 生命 8 币 / 回满 18 币）、**属性加成**（攻击 +1、生命上限 +2、移速 +8%、攻速 +10%，全部永久）、**武器**（铁剑 20 币 + 4 种元素剑 26~38 币，需先持有环剑）与**武器属性**（剑油 +15% 剑伤害 18 币、磨剑石 +5% 剑暴击 22 币，同样只加剑不加主角）。第 15 回合是最后一关，清完直接结算不弹商店。
- **元素剑**：每把剑都有一种元素，命中触发附加效果（见 `swordKinds.js`）——**铁剑**（无附加）、**毒剑**（中毒：每秒 0.1 持续 5 秒，绿色飘字）、**冰剑**（减速 35% 持续 2.5 秒，脚下蓝圈提示）、**雷剑**（对 4.5 内最近 1 只怪连锁闪电，60% 伤害，紫色电弧）、**血剑**（按伤害 15% 回血）。环上可混装，技能栏按获得顺序展示每种剑的数量；三选一里有对应的强化项（淬毒/严寒/导电/活血）。
- **武器 · 环剑**（第 5 回合打完自动获得）：三把铁剑环绕主角旋转（半径 1.7、剑刃外扬 35°），各有自己的判定，碰到怪砍一刀后**这把剑消失**；被消耗的剑每 3 秒恢复一把（属性「剑回复」可加快），上限 3 把（属性「剑数量上限」可提高；上限买高了会自动补铁剑）。
- **武器属性与主角彻底独立**（第 6 块定案）：剑伤害 1.6、**自带 10% 暴击**、暴伤 150% —— 全是环剑自己的数值，**主角的攻击力 / 暴击 / 吸血一点也影响不到剑**（反过来剑系升级也不碰主角）。升级、商店、事件三处都靠 `scope: 'weapon'` 路由到武器表。
- **技能 · 万剑齐发**：右下角技能栏第 1 格（共 6 格，3 行 2 列；第 2~6 格展示拥有的元素剑与数量）。按一下，环上 n 把剑全部射出，**同时在每两把之间再插入一把 —— 一次射出 2n 把**（插入的剑沿用前一把的元素）；**剑身与判定半径都放大到原来的 1.4 倍**（剑长 1.75、判定半径 0.77）。插入的剑从对象池临时取，飞完/命中就回池，不影响环上计数。命中怪造成同款伤害后消失，出界自动散掉。**无冷却**——有剑就是激活态，没剑变灰并在底部显示恢复进度。按钮监听 `pointerdown` 而非 `click`：手机上一根手指推摇杆时另一根手指点按钮，iOS 不派发 click，这正是「移动中技能点不动」的根因。
- **获得武器（第 5 回合）**：清空后先弹「环剑」获得卡（图标 / 效果说明 / 装备按钮），关掉再进三选一 —— 从这一回合起剑系强化才进抽取池。
- **怪物头顶血条**：常驻显示（满血也在），条内带精确数值（如 2.0/3.0，保留一位小数），低于 50% 变黄、25% 变红；挂在头顶上方不被头部遮挡。
- **属性面板**：左上角常驻血条（生命保留一位小数）+ 金币角标 + 三个关键属性（攻击力/攻击范围/移速）；点血条或「属性 ▸」展开完整面板——**分「奶蛙 / 环剑」两页**（页签切换），页内再按组显示（奶蛙：生存/近战/机动/经济；环剑：剑本体/元素），**打开即暂停游戏**（怪物/计时/环剑全冻结），点空白处 / ✕ / Esc 关闭并恢复。
- **数值全部保留小数**：伤害飘字、怪物血条、属性面板、结算面板统一 1 位小数（生命 6.0、攻击力 1.0、伤害 2.4、暴击率 0.0%）。伤害本身早就是小数（防御减伤公式输出小数），显示取整会让玩家看不出差异——现在统一不取整。
- **数值是活的**：移速直接驱动角色实际跑动，属性加成改了立刻生效；生命回复逐帧结算。
- 左上角 HUD 显示 FPS / 速度 / 坐标 / 朝向 / 场上怪数（0.25s 刷新一次，朝向已规范到 0~360°）；右上角是波次进度。

## 敌人图鉴

| 怪物 | 生命（第 1 回合） | 速度（第 1 回合） | 行为 |
|---|---|---|---|
| 骷髅小兵 | 1 | 2.30 | 从场边钻出，冲脸，**碰到主角自毁并造成 1 点伤害**；三种怪里最快 |
| 骷髅战士 | 3 | 1.15 | 最慢（穿甲），追到近战距离（1.55）停下挥拳，每 1.7 秒 1 点伤害；**攻击不扣自己的血**；抬手 0.45 秒有红圈预警，可以躲 |
| 骷髅投手 | 2 | 1.50 | **远程**（第 11 回合起登场）：站 4.2~7.0 距离，进射程拉弓 0.72 秒（脚下橙色脉冲）后掷骨刀——直线弹道、速度 5.6、命中 1 伤，朝出手瞬间的位置飞，走位就能躲；主角贴到 4.2 内会后退风筝，但移速慢，追上去能秒 |

⚠️ 表里的速度是**基准值**：每只怪生成时还会在 ±15% 内随机浮动，所以同一波怪不会齐步走。

生命/伤害/速度按回合倍率成长（取整规则见 `wave.js` 的 `roundScale`），倍率只落实到每只怪的实例上，不改全局配置。

刷怪规则：只从场边圆环（半径 13.2±0.5）钻出；与主角距离 ≥7（主角贴边时从对面来）；相邻两次刷怪至少隔 2 个单位。出生有钻地动画和传送圈，期间无敌不动。每回合出场顺序：小兵 → 战士 → 投手。

**怪群分散四件事**（第 6 块，防抱团）：① 三种怪基础速度拉开（2.30 / 1.50 / 1.15）；② 同种怪生成时速度 ±15% 随机；③ 每只怪走 3~6 秒就随机停下休息 0.7~1.5 秒（各不相干）；④ 路线不是直线 —— 每只怪带随机相位与摆幅（约 6°~17°）的横向弧线，越靠近主角摆幅越小（免得绕圈打不到人）。加上原有的碰撞分离，怪很难再叠成一坨。

第二关预案（模型已入库，未实现）：**骷髅巫师**（读条范围法术，光环给周围小怪 +30% 攻速，命中给主角 3 秒减速 debuff），见 `enemy.js` 的 `mage` 配置。投手原本也是预案，现已实装。

## 运行

浏览器不允许 `file://` 下的 ES Module 与 fetch，所以**不能双击 index.html**，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到任何静态托管（GitHub Pages / Netlify / Nginx）都是「整个仓库根目录当站点根」，无需构建。

## 技术要点

- **Three.js 固定 r160**，本地内置运行时零外部请求。
- **手机兼容是硬约束**：不用 importmap、不用顶层 await —— iOS 16.4 以下的 Safari、旧版微信/安卓 WebView 不支持 import maps，iOS 15 以下不支持顶层 await，任何一条都会让整个模块解析失败、加载页永远停在 0%。所有 import 都写相对路径（`../lib/three.module.js`），主流程包在 `boot()` 里，index.html 末尾有兜底自检（模块 9 秒没跑起来就在加载页写明原因），GLB 下载进度在拿不到 Content-Length 时按文件大小估算。改加载相关代码时这三件事别回退。
- 奶蛙：单网格无骨骼 → `frog.js` 程序化 7 骨 + 距离蒙皮，腿骨枢轴在胯部；正面朝 +Z。
- 怪物：KayKit 模型自带 41 骨骼蒙皮与动画 → `SkeletonUtils.clone` 克隆实例 + 每只独立 `AnimationMixer`；材质逐实例克隆（受击闪白不串场）。
- **怪物身高标定是坑**：KayKit 模型的几何包围盒 / `boneTransform()` 与实际渲染差得极远，`ENEMY_TYPES` 里的 `sourceHeight` 是原点参照物截图实测值（minion 1.05 / warrior 1.15 / archer 1.10），换模型必须重测（也可用 `applyBoneTransform()` 蒙皮顶点法做相对校验）。`height` 是按 `sourceHeight` 归一后的世界身高，血条/特效都用它。
- **头顶血条**（`enemy.js` 的 `createBar`）：canvas 贴图 Sprite，**必须 `depthTest: false`**（否则俯视相机会被怪自己的头从中间挡住）+ `position.y = height + 0.95`（贴太近会横穿脸部）；`draw(ratio, hp, maxHp)` 顺带把数值画进条里。
- **体型基准**：主角 `frog.js` 的 `RIG.TARGET_H = 2.28`（原始 1.9 × 1.2），怪物 `height` 取 0.8 折（minion 1.14 / warrior 1.38 / archer 1.28）——视觉上主角略高于小兵、矮于战士。
- **回合成长**（`wave.js`）：`rounds` 表驱动（15 回合，含投手列），`roundScale(r)` 给出 hp/damage/speed 倍率；`spawn(type, at, {hpScale, damageScale, speedScale})` 倍率**只落实到实例**，绝不改 `ENEMY_TYPES`。要调强度改 `rounds` 或倍率公式。
- **远程怪 · 骨刀弹道**（`enemy.js`）：投手 AI = 距离 < `keepDistance`(4.2) 后退、> `attackRange`(7.0) 靠近、之间站定拉弓（前摇 0.72 秒，脚下橙色脉冲蓄力圈）→ `throwBone()` 生成共享几何的骨刀 Mesh，直线飞行（速度 5.6、寿命 2.6 秒、出界消失），水平面判定命中主角（半径 0.30 + 主角半径）。骨刀只朝出手瞬间的主角位置飞，不追踪。**第 6 块按反馈全面下调：伤害 2→1、间隔 2.6→3.6 秒、弹速 8.5→5.6、前摇 0.55→0.72**。弹体几何/材质全系统共享一份，移除时只 `scene.remove` 不 dispose。
- **怪群分散**（`enemy.js`）：`spawn` 时 `speedMul = 0.85 + rng×0.30` 落在实例上；`restCd/restT` 驱动随机休息（出手时不歇）；`moveToward` 里把「指向玩家」的方向绕竖轴旋转 `driftAmp × near × sin(t×driftFreq + phase)`——`near = dist/2.5` 让摆幅在贴脸时收小，避免绕圈打不到人。三个参数都在生成时随机，配合碰撞分离实现「不抱团」。
- **环剑**（`weapon.js`）：剑模型 Kenney《Mini Dungeon》（CC0，9KB）；**剑刃必须外扬 35°**——顶视角相机下平躺的剑只剩一条线，根本看不见。**剑身整体放大 1.4 倍**（`SWORD_SCALE`，判定半径同步 0.55→0.77）。**多元素实现**：`protoFor(kind)` 克隆模板后逐网格克隆材质，按 `SWORD_KINDS` 调 color/emissive（自发光 2.2，深夜 + ACES 会吃饱和度）；对象池按元素分池。`owned` 数组记录拥有的剑（按获得顺序），环上数量 = min(owned, swordMax)；被消耗的剑按「owned 里有、环上没有」优先恢复；上限买高了自动补铁剑。`fire()` 一次射出 **2n 把**：原有 n 把沿各自朝向 + 在每两把之间插入一把（沿用前一把元素）。命中 → `applyKind()`：毒挂 DoT（`enemy.applyDot`，0.5 秒一跳）、冰挂减速（`applySlow`）、雷 `chainTargets` 连锁 + 手绘 Line 电弧（0.22 秒淡出）、血按伤害回血。模型加载失败自动换双盒占位剑。
- **金币**（`gold.js`）：击杀回调里按 `goldRate` 掷骰 → 金币 Mesh（共享几何/材质）弹起自转，0.5 秒后销毁并 `onGold(1)` 入账。金币不是属性，是本局货币，只在商店花。
- **随机事件**（`events.js` + `main.js`）：事件表声明式（`effects` 只描述「mods/gold/hp/drain/level/pledge/roll」，`main.js` 的 `applyEffects` 统一落地）。回合 buff 用独立 src `event:<回合>` 挂 stats，`clearRoundBuffs()` 在下一回合开始前整批撤销；伏笔 `pledge` 存队列，到期回合开始时弹回报卡，其 mods 是**永久**的（src 不同不会被清）。`level.applyRoundMod()` 让事件能改本回合怪物数量/移速——`wave.js` 的刷怪表**延迟到事件选完才展开**，所以顺序天然正确。
- **回合链**：回合清空 → （武器卡）→ 三选一 → 商店 → 下一回合。每个面板关闭时通过 `after` 回调接续下一段，全部关闭才恢复 `playing`。
- **属性分两块表**（第 6 块）：`stats.js` 泛化成 `createStats(defs)`，主角 `STAT_DEFS`（11 项）与武器 `WEAPON_STAT_DEFS`（12 项）各造一个实例，公式与减伤完全同一套。剑击伤害走 `rollSwordDamage(wstats)`，**不读主角任何数值**。升级/商店/事件里 `scope:'weapon'` 的条目落到 `wstats`，其余落到主角；事件 buff 撤销时两张表都要清。属性面板按 defs 的 `group` 字段分组、按页签渲染。
- **升级三选一**（`upgrade.js`）：基础值为 0 的属性（暴击率/吸血/剑暴击率）**必须用 `flat` 加成**——百分比公式是 `(base+flat)×(1+pct)`，base=0 时 pct 完全无效。加成经 `addMod` 带 `src` 标识，可整批撤销。武器系升级带 `needsWeapon` 标记，没拿到环剑前权重为 0。每项权重 `w0 + gw × (回合-1)`，`chanceTable(round)` 能算出任意回合各选项的概率（`关卡事件表.txt` 就是它生成的）。
- **开局状态机**（`main.js`）：`title → tutorial | playing → event | upgrade | weapon | shop → over`。`?debug=1` 自动跳过标题页与教程**并且跳过随机事件卡与商店自动弹出**（测试需要确定性开局；手动 `__game.shop.open()` / `__game.event.trigger(id)` 仍可测）；`?debug=1&story=1` 保留叙事；`?debug=1&title=1` 保留标题页。教程第 2 步的靶子 0 伤害 1 血，`damageScale` 会被四舍五入回 1，所以要手动 `tutDummy.damage = 0`。
- 距离与索敌在 `stats.js`：`distance2D`（只算水平面）/ `inRange2D` / `nearestInRange`（射程内最近、自动跳过死者）；`stats.findTarget()` 用当前攻击范围。
- **范围环**（`rangeRing.js`）所有环共用一张 canvas 环贴图 + 一块半径 1 的平面（`scale` 当半径），加色混合、贴地 y≈0.03、`depthWrite:false`，不和地面抢深度。主角环挂在场景上跟 `pos` 走 —— 角色模型走路/倒地会让 `root.y` 起伏，挂身上环会浮起来；怪物环挂在各自 root 下，死亡缩小/下沉时自然一起消失。要改粗细/亮度就改贴图的渐变 stop 与 `opacity`。
- 主角受击有 **0.55 秒无敌帧** + 屏幕红闪 + 相机震动，防止被多只小兵同帧秒杀。
- 属性加成模型：`(基础值 + Σ加法) × (1 + Σ百分比)`，`stats.addMod({stat, flat|pct, src})` / `removeBySource(src)`。
- 调手感：`main.js` 顶部（ACCEL/TURN_SPEED/CAM_OFFSET/ARENA_R/IFRAME）；调战斗数值：主角 `stats.js` 的 `STAT_DEFS`、**武器 `weaponStats.js` 的 `WEAPON_STAT_DEFS`**、`enemy.js` 的 `ENEMY_TYPES`（含投手三处削弱值）、`wave.js` 的 `rounds`/`roundScale`、`upgrade.js` 的 `UPGRADES`、`weapon.js` 顶部（ORBIT_R/SWORD_LEN/SWORD_HIT_R/FLY_SPEED）；调商店价格：`shop.js` 的 `SHOP_ITEMS`；调事件：`events.js` 的 `EVENTS`。
- `?debug=1` 暴露 `window.__game`（内部状态 + 受控生成怪 + 冻结波次/怪物），自动化测试专用，正常游玩不暴露。
