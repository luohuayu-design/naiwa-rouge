# 蛙步 · 夜行（naiwa-rouge）

一个用 Three.js 做的**幸存者类肉鸽游戏**原型。角色是「奶蛙」，来自同作者的音游《蛙步》。
当前完成第 3 块：**3D 角色 + 浮动摇杆 + 可行走场景 + 属性系统 + 10 回合关卡 + 三选一升级成长**（怪物 AI、回合属性成长、升级闭环、胜负结算均已上线）。

在线试玩：<https://luohuayu-design.github.io/naiwa-rouge/>

## 玩法

- 深夜草地圆形竞技场，可走半径 15（边界是发光草圈 + 石头圈，撞边会沿切向滑走，穿不出去）。
- **移动**：左半屏任意位置按住拖动，浮动摇杆就在落点出现；键盘 WASD / 方向键同样可用（斜向已归一化）。右侧 42% 屏幕预留给后续技能键。
- **自动近战**：攻击范围（2.1）内有怪就自动出手，攻击频率是属性 `attackSpeed`（初始每秒 1.2 次，升级可加快），出手瞬间转向最近的目标并播放「抬手 → 拍下」的攻击动作（0.34 秒，叠加在走/跑动画之上）；没有目标不空挥。挥击有冲击环特效。
- **范围环**：主角脚下有一圈青色光环，半径就是当前攻击范围（升级加范围会立刻变大）——站到环边就正好够不着。骷髅也都画着自己的圈：小兵是暖橙色的自爆接触圈（主角半径 + 接触距离），战士是红色的近战圈（1.55），看到环压过来就该退。
- **第一关 · 荒草地**：**10 个回合**，共 61 只小兵 + 18 只战士（79 只）。每回合必须清完才进下一回合（没有超时跳过）。**怪物随回合变强**：第 10 回合生命 ×2.44、伤害 ×1.90、速度 ×1.315（小兵第 5 回合起 2 刀一只，战士 3 → 7 血、伤害 1 → 2；主角 4.4 移速始终跑得过最快的怪）。清完全部 → 通关；生命归零 → 倒下。结算面板显示用时/击杀/回合/升级次数/剩余生命/攻击力。
- **三选一升级**：第 1 / 3 / 5 / 8 / 10 回合清空后暂停，弹出三张卡（**进攻 / 生存 / 机动**三系各抽一张，共 12 项：锋利、连击、长臂、锐目、致命、厚皮、甲壳、再生、吸血、轻功、疾风、游刃）。选哪张立即生效，第 10 回合的最后一格选完直接通关。面板打开时世界完全冻结。
- **怪物头顶血条**：常驻显示（满血也在），宽随身高，低于 50% 变黄、25% 变红；挂在头顶上方不被头部遮挡。
- **属性面板**：左上角常驻血条（生命 6/6，低于 50% 变黄、25% 变红）+ 三个关键属性（攻击力/攻击范围/移速）；点血条或「属性 ▸」展开完整面板（10 项属性 + 说明），点空白处 / ✕ / Esc 关闭。
- **数值是活的**：移速直接驱动角色实际跑动，属性加成改了立刻生效；生命回复逐帧结算。
- 左上角 HUD 显示 FPS / 速度 / 坐标 / 朝向 / 场上怪数（0.25s 刷新一次，朝向已规范到 0~360°）；右上角是波次进度。

## 敌人图鉴

| 怪物 | 生命（第 1 回合） | 速度（第 1 回合） | 行为 |
|---|---|---|---|
| 骷髅小兵 | 1 | 2.15 | 从场边钻出，直线冲脸，**碰到主角自毁并造成 1 点伤害** |
| 骷髅战士 | 3 | 1.32 | 追到近战距离（1.55）停下挥拳，每 1.7 秒 1 点伤害；**攻击不扣自己的血**；抬手 0.45 秒有红圈预警，可以躲 |

生命/伤害/速度按回合倍率成长（取整规则见 `wave.js` 的 `roundScale`），倍率只落实到每只怪的实例上，不改全局配置。

刷怪规则：只从场边圆环（半径 13.2±0.5）钻出；与主角距离 ≥7（主角贴边时从对面来）；相邻两次刷怪至少隔 2 个单位。出生有钻地动画和传送圈，期间无敌不动。

第二关预案（模型已入库，AI 未实现）：**骷髅投手**（远程，射程 6.5，骨刀有弹道可躲）与**骷髅巫师**（读条范围法术，光环给周围小怪 +30% 攻速，命中给主角 3 秒减速 debuff），见 `enemy.js` 的 `archer`/`mage` 配置。

## 运行

浏览器不允许 `file://` 下的 ES Module 与 fetch，所以**不能双击 index.html**，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到任何静态托管（GitHub Pages / Netlify / Nginx）都是「整个仓库根目录当站点根」，无需构建。

## 技术要点

- **Three.js 固定 r160**，本地内置运行时零外部请求。
- **手机兼容是硬约束**：不用 importmap、不用顶层 await —— iOS 16.4 以下的 Safari、旧版微信/安卓 WebView 不支持 import maps，iOS 15 以下不支持顶层 await，任何一条都会让整个模块解析失败、加载页永远停在 0%。所有 import 都写相对路径（`../lib/three.module.js`），主流程包在 `boot()` 里，index.html 末尾有兜底自检（模块 9 秒没跑起来就在加载页写明原因），GLB 下载进度在拿不到 Content-Length 时按文件大小估算。改加载相关代码时这三件事别回退。
- 奶蛙：单网格无骨骼 → `frog.js` 程序化 7 骨 + 距离蒙皮，腿骨枢轴在胯部；正面朝 +Z。
- 怪物：KayKit 模型自带 41 骨骼蒙皮与动画 → `SkeletonUtils.clone` 克隆实例 + 每只独立 `AnimationMixer`；材质逐实例克隆（受击闪白不串场）。
- **怪物身高标定是坑**：KayKit 模型的几何包围盒 / `boneTransform()` 与实际渲染差得极远，`ENEMY_TYPES` 里的 `sourceHeight` 是原点参照物截图实测值（minion 1.05 / warrior 1.15），换模型必须重测。`height` 是按 `sourceHeight` 归一后的世界身高，血条/特效都用它。
- **头顶血条**（`enemy.js` 的 `createBar`）：canvas 贴图 Sprite，**必须 `depthTest: false`**（否则俯视相机会被怪自己的头从中间挡住）+ `position.y = height + 0.95`（贴太近会横穿脸部）。
- **回合成长**（`wave.js`）：`rounds` 表驱动，`roundScale(r)` 给出 hp/damage/speed 倍率；`spawn(type, at, {hpScale, damageScale, speedScale})` 倍率**只落实到实例**，绝不改 `ENEMY_TYPES`。要调强度改 `rounds` 或倍率公式。
- **升级三选一**（`upgrade.js`）：`STAT_DEFS` 里基础值为 0 的属性（暴击率/吸血）**必须用 `flat` 加成**——百分比公式是 `(base+flat)×(1+pct)`，base=0 时 pct 完全无效。加成经 `stats.addMod` 带 `src` 标识，可整批撤销。
- 距离与索敌在 `stats.js`：`distance2D`（只算水平面）/ `inRange2D` / `nearestInRange`（射程内最近、自动跳过死者）；`stats.findTarget()` 用当前攻击范围。
- **范围环**（`rangeRing.js`）所有环共用一张 canvas 环贴图 + 一块半径 1 的平面（`scale` 当半径），加色混合、贴地 y≈0.03、`depthWrite:false`，不和地面抢深度。主角环挂在场景上跟 `pos` 走 —— 角色模型走路/倒地会让 `root.y` 起伏，挂身上环会浮起来；怪物环挂在各自 root 下，死亡缩小/下沉时自然一起消失。要改粗细/亮度就改贴图的渐变 stop 与 `opacity`。
- 主角受击有 **0.55 秒无敌帧** + 屏幕红闪 + 相机震动，防止被多只小兵同帧秒杀。
- 属性加成模型：`(基础值 + Σ加法) × (1 + Σ百分比)`，`stats.addMod({stat, flat|pct, src})` / `removeBySource(src)`。
- 调手感：`main.js` 顶部（ACCEL/TURN_SPEED/CAM_OFFSET/ARENA_R/IFRAME）；调战斗数值：`stats.js` 的 `STAT_DEFS`、`enemy.js` 的 `ENEMY_TYPES`、`wave.js` 的 `rounds`/`roundScale`、`upgrade.js` 的 `UPS`。
- `?debug=1` 暴露 `window.__game`（内部状态 + 受控生成怪 + 冻结波次/怪物），自动化测试专用，正常游玩不暴露。
