# 蛙步 · 夜行（naiwa-rouge）

一个用 Three.js 做的**幸存者类肉鸽游戏**原型。角色是「奶蛙」，来自同作者的音游《蛙步》。纯静态站点（无构建、无 CDN、零依赖，Three.js r160 本地内置），GitHub Pages 发布，手机浏览器兼容是硬约束（不用 importmap / 顶层 await）。

在线试玩：<https://luohuayu-design.github.io/naiwa-rouge/>

当前完成第 82 块（**v=93**）：标题页 + 新手教程 + 3D 角色 + 浮动摇杆 + 主角/武器两套独立属性 + 20 回合关卡（**9 关**）+ 升级成长（**71 卡**：22 条属性 × 小/中/大三档 + 5 张整卡，五档品质）+ 武器系统（环剑 + 6 种元素剑 + 万剑齐发 / 箭雨 / 回血）+ 金币/商店 + 随机事件（**131 个**，含主线番外 10 条，对话普遍 100~180 字）+ 音效与 BGM + 图鉴（**21 只怪**）/成就（**41 条**）/战绩/难度 + 夜行商店（篝火 + 盲盒两区） + 永夜火种 + 夜行诅咒 + 今日挑战/种子 + 礼包兑换 + 公告/宣传有礼 + 每日签到 + 主线剧情《笑不出来的那一夜》+ 第七关「骨塔井底」（窄井 + 井底滴水落点 hazard + 井蛙吐舌拉人 / 木鱼灵吐追踪泡定住你两只新怪 + 木鱼法器）+ 第八关「骨塔寄存层」（**不追人的骷髅队列** + **旗手崩散 4 秒** + **寄存柜攒 8 块木牌放出一支新队伍**）+ 第九关「骨塔登记庭」（**称量官给全场叠记名层** + **砍掉它当场清零**）+ 攻略面板 + 管理员模式 + **存档备份**（导出文件 / 复制存档码，换设备导回来）。

## 玩法

- **场景 / 移动**：深夜草地圆形竞技场，可走半径随关卡 15~20（撞边沿切向滑走）。左半屏按住拖动出浮动摇杆；WASD / 方向键也可用。右侧预留技能键。
- **开始 / 选关**：加载完进标题页 → 选「开始游戏」先选关卡（通关上一关才解锁）→ 选难度 / 诅咒 → 问是否教程 → 开打。第一关 20 回合共 273 只，怪随回合变强（R20 生命 ×4.04 / 伤 ×2.90 / 速 ×1.67），清完通关、生命归零倒下。
- **存档**：每回合自动落档；局内「存档退出」回主菜单；主菜单「读取存档」列中途退出的局（按退出时间排序）；彻底打完自动清档。调试局（`?debug=1`）默认不落档，要落加 `&keepsave=1`。
- **存档备份（第 78 块）**：设置里多了「存档备份」四个键 —— **导出文件**（`.json` 落盘）、**复制存档码**（一串 `NWSAVE1:` 打头的 base64，塞进微信发给自己也不会被折行截断）、**导入文件**、**粘贴存档码**（空格换行都不管，粘错会在框里直接说原因）。
  - **只带真正有价的**：篝火 / 骨币 / 永夜火种 / 夜行商店（宝箱、永久法器、技能 CD）/ 图鉴 / 成就 / 战绩 / 剧情进度 / 签到 / 在途局。
  - **故意不带**：音量与静音（换台设备本来就该重调）、管理员标记（别跟着存档到处跑）、公告与宣传的已读（换机器该重看一遍）、`profile.settings` 整块（摇杆尺寸 / 位置、画质、震动、速度感 —— 导入时沿用**本机**那份，免得把别人手机的摇杆尺寸搬过来）。
  - 导入前会弹一次确认，把「这份存档里有什么」和「本机现在是什么」两组数字并排列出来，明确了「盖了不能撤回」才写盘；导入后自动刷新一次页面生效。
  - 为什么不能做得更省事：浏览器没有任何办法替玩家保住 `localStorage` —— 清缓存 / 无痕 / 换设备时页面自己一点办法都没有（没有跨设备持久存储，也不能偷偷写到玩家的网盘）。所以只能给一条手动备份的路。
- **对话读秒**：主线与奇遇每拍一两百字，回话按钮先锁 3s 才亮（个别事件可在数据里写 `readDelay:0` 单独关掉）。
- **永久选择提示**：篝火与永夜火种写进整个存档、不可撤销，首次各弹一次告知 + 页面常驻警示条。
- **礼包兑换**：主菜单输码换夜行骨币（纯前端、不用服务器）。A 类 300 / B 类 100 / **推荐礼包 100 ×10** / **宣传礼包 300 ×10** 共 40 码，一码一机一次；码表只存哈希，明文在 `gift-codes.local.md` 与 `兑换码大全.txt`（gitignore，别提交）。换浏览器/清缓存/换设备 = 记录清零，同码可再用。
- **属性页**：3D 奶蛙展台，按住拖动旋转、松手回正，定时蹦跳拍掌；按 生存/近战/元素/局外 列 14 项（算上篝火与火种，被加成的行标「基础 X」）。
- **音效包**：默认 32 个 CC0 素材；打通第一关后可换 4 段奶蛙叫声替换 8 个位置（拍中/暴击/受伤/怪死/自爆/清回合/通关/倒下），设置里随时切回。
- **每日签到**：以周为大单位 —— 周一 00:00 开新的一周，每天签到 +20 骨币，一周内累计 3 天 +100、6 天 +200（不要求连续，断签不清零；跨周清零）。公告关掉后自动接一次（今天签过就不再弹），主菜单「今日挑战」那排有常驻入口，没签的那天按钮上带红点。
- **公告 / 宣传有礼**：进主界面自动弹公告（提建议/报 bug 发码 + QQ「落花雨 3829845261」+ 网址，均一键复制；勾「今日不再」当天不弹）；关掉公告后接一记「宣传有礼」艺术字特效 → 展开正文（推荐朋友每人 100 / 视频动态 300 / 赞评藏各 5 骨币，联系本人，11 月 30 日统一结算）。主菜单第三排「📢 公告」、第五排「🎁 宣传有礼」随时强制回看。
- **教程**：**八步**新手教程（走路 → 判定环 → 打第一只 → 升级三选一 → 属性面板 → 技能栏 / CD 读秒 → 背包 → 开局），第 2 步专门讲「脚下这圈光就是你的攻击范围，走位是把怪带进圈里」；拿新武器自动弹武器教程（每种只教一次，可跳过，技能栏会整栏上移让开卡片）。另外两种「**一次性提示卡**」（第 65 块）也走同一套卡片外观：拿到回血技能后第一次进关教你那个绿十字、第一次被擦名者读条教你头顶那条百分比 —— 都是**世界完全暂停**、只弹一次、写进本机档案。
- **自动近战 / 范围环**：范围内自动出手（频率 = 属性 attackSpeed）；脚下青环 = 攻击范围。骷髅也都画自己的圈：小兵暖橙自爆接触圈、战士红近战圈。
- **三选一成长**：每回合清空后暂停弹三张卡（进攻/生存/机动 28 项 + 武器系 10 项），显示原值→选后值，带五档品质（普通/稀有/精良/史诗/传说，是抽签权重而非装饰）；**幸运**只放宽高档。剑系 9 张（剑伤害 / 暴击 / 击杀吸剑 / 转速 / 锻剑 / 淬毒 / 严寒 / 导电 / 回春）第 64 块整体约**翻倍**，例如剑伤害 +30%→**+60%**、淬毒 +0.05→**+0.12**。面板打开时世界冻结。
- **随机事件 · 夜行奇遇**：**131 个事件**（99 随机 + **10 条主线番外** + 13 连锁后续 + 9 民心专属）、305 个可选项，回合结束抽 1 个（同事件 3 回合不重复），效果落下一回合；带 `cost`/`roll`/`chain`/`permanent`。`民心`(0~120，开局 50) 影响商店价 0.65~1.25×、金币掉落 ±8%、部分事件出现条件；**跨档位会触发专属事件**（涨到新档抽良性池 5 条、跌到新档抽恶性池 4 条，同一档一局只来一次，见 `js/repEvents.js`）。**播放时机（第 67 块，用户定案）**：就在**这一回合**的结算链里 —— 随机事件 → 三选一（这回合该有的话）→ 民心事件 → 商店；这回合没有三选一的，随机事件一关就立刻弹。原来它排在下一回合的奇遇时段、还让位给主线，玩家选完事件得再打一整回合才看到，体感就是「民心升档根本没弹」。关底也照播（选完三选一 → 民心事件 → 结算）。
- **金币 / 商店**：打死怪概率掉金币（落地 3 秒入账，进攻击范围自动拾取）；每 3 回合弹商店随机摆 4 件（药水/属性/武器/武器属性/法器），同一件一次进店只买一件（买完售罄）。
- **装备**：弩炮台（上限 3，自主索敌）、**法器**（地刺/霜环/震钟/棘甲/暖炉/路口灯/绝缘斗篷/**木鱼**，各 3 级，被动或周期触发；木鱼在挨打 / 击杀时震一圈，把身边怪击退 + 短暂定身，是窄井里被围时的救命底牌）、金钟罩（每 15s 护体 3s 无敌，多层减周期）；背包（B 键，药水入包再喝）。
- **元素剑 / 环剑**：6 种元素剑（铁/毒/冰/雷/血/震）——**除铁剑外全是群体效果**：毒/冰/血/震波及命中点 **7.0 格**内一圈（冰直接冻 1.6 秒、毒 0.15/秒、血按一圈总伤害回血、震 35% 击退打断），雷剑唯一全场连锁（每道 45%）；波及半径（7.0 格）与溅射比例（50%）在武器属性页可见；环剑 3 把环绕、整环补满、数量无上限；**万剑齐发**（技能键第 1 格，辐射 n=拥有数，6s CD，不影响环上剑）、冷却倒计时精确到两位小数、**箭雨**（第 2 格，最近一堆怪头顶落箭）、**回血**（第 3 格，第 4 关通关后永久解锁，瞬回 5 点、25s CD、满血不掉 CD；键面是**绿色十字 + 外圈充能环**，第一次进带着它的关卡会弹一张卡教怎么用）。
- **技能只看「解锁」不看「第几关」**（第 65 块）：环剑 / 箭雨 / 回血只要永久解锁过，**任何关卡开局都直接带着**——回头重打第一关，第 5 回合那次「首次得剑」的仪式跳过，开头就有 3 把剑和两个技能键。**新手教程期间技能栏也是亮的**（第 66 块）：八步教程有一讲就是讲右下角技能栏，原来那一刻整栏是隐藏的（开局初始化要等教程结束才跑），等于对着空气讲。现在教程入场就把「解锁过的技能」静默放上去 —— 老玩家重打第一关，讲技能栏那一刻三格都在。
- **箭雨教程不会再卡死**（第 66 块）：武器教程最后一步要求「现在就按一次试试」，但教程期间波次是停的、拿武器又刚好在回合结算之后 —— 场上一只怪都没有，而箭雨在空地按不动（刻意设计，不让人白扔 8 秒 CD）。于是那一步永远等不到箭雨落地。现在这一步会**自动放两只靶子**，打完没按就再补。教程之外空地按箭雨，奶蛙头顶会冒一句「附近没有怪」，不再是静默失败。
- **点不动的两个真 bug 都修了**（第 66 块）：① 收起的教程卡只是 `opacity:0`，里面那个「知道了」按钮仍 `pointer-events:auto`，一块 398×39 的**隐形按钮正好压在屏幕正中**——随机事件的选项、三选一中间那张卡，点上去有三分之一落空，手感就是「很迟钝」。现在卡片收起后 `visibility:hidden`，连命中测试都不参加；卡片里的按钮也统一成「只有卡片亮着才吃点击」。② 箭雨的 8 秒冷却原来会**跨局残留**（重开一局开局就是灰的），现在每局从 0 起。
- **属性面板**：三页签（主角 / 武器 / **技能**）——武器页 12 项环剑属性，技能页把三个技能连同 **CD 时长 / 当前状态（就绪 / 冷却中·还剩 x.xx 秒 / 满血 / 未解锁 + 解锁条件）** 全列出来，箭雨没解锁也查得到。
- **攻略面板**：战败面板「温馨提示」上多了「查看攻略」；手风琴三组（武器 / 属性 / 技能），每条讲「它到底是什么 → 什么时候最强 → 什么时候别指望它」（例：雷剑怪越多越强、万剑齐发留到被围的时候），正文里的 `**重点**` 会渲染成加粗。
- **后续关卡**（每关 20 回合，难度递增）：二关「骨塔庭院」（三巫师各一技 + 双主题）、三关「焦土钟楼」（冲锋蛮牛/盾斧兽人/孢生菇 + 震钟/棘甲/震剑）、四关「雾堤服务区」（雾鬼隐身无敌/雾猎狼落点跳劈/缝补小巫群奶 + 暖炉）、五关「草甸路口」（**四向路口**：怪只从东南西北四条路上来，可以提前站位；新怪擦名者偷你环上的剑、得手就跑（**第 75 块：它改成在刷怪进度 40%~60% 的中段登场、出生在更近的圈上、并且会主动走到你身边 4 格处缠着**，不再「最后只剩它一个慢慢挪」） + 路口灯反隐）、六关「骨塔机房」（**漏电地板**周期通电，站上去每 0.6 秒掉 **2 血**、**无视防御** + **重启体**死后 4 秒半血重启、最多 1 次 + **并联体**：悬浮的旧发电机，**场上所有并联体两两之间拉一条电弧**（4 只 = 6 条），碰到就掉血、拆掉一只就少一条线 + 绝缘斗篷以毒攻毒）、七关「骨塔井底」（**窄井 arena 13**：转身空间很紧；**井底滴水落点 hazard**——头顶水随机落下，青环预警后溅伤，不依赖某只怪在场；新怪**井蛙**吐舌头把主角拉过去、舌头有独立血量要先砍断、砍断后井蛙短硬直，**木鱼灵**青圈减速你、血薄站后排；法器**木鱼**被动挨打/击杀震一圈击退定身）。**八关「骨塔寄存层」**（**不追人的骷髅队列**：无名者沿固定方向平移、撞边界才换向，撞到掉血并把沿队伍侧面挤开；队列中间举木牌的**旗手**一倒，整排站住 4 秒且受双倍伤害 + **寄存柜**：死掉的无名者/旗手各掉一块木牌进柜，攒满 8 块开门放出一支自带旗手的新队伍，站桩 1.1 秒能先取 2 块，场上队伍太多则改放电）。**九关「骨塔登记庭」**（第 82 块，接剧情 s09《名字的重量》）：新怪**称量官**抱着一本台账、站得极远，自己几乎不打人，活儿是**给全场记账** —— 每隔 9 秒把它那本簿子翻开一次，场上所有存活的怪一起加移速 / 伤害 / 减伤，最多 5 层；被记名的怪脚下会长出一只**金环**（层数越大环越大），一眼能数出这一层记到第几层。**砍掉它，所有层当场清零**，所以输出窗口只有它站定念簿子那 2.2 秒；第三幕起上两只、第五幕三只 —— 那时候「绕后拆它」不再是单选题。剧情 s05 / s06 / s07 / s08 / s09 分别绑在五、六、七、八、九关第 2 回合。
- **五、六关难度**（第 65 块按实测反馈抬的）：整关乘数 **伤害 ×1.35 / 血量 ×1.15**（写在关卡表 `scale.dmgMul / hpMul`，只抬这两关，前四关一点没动）。
- **擦名者的读条看得见了**（第 65 块）：它在远处站定读条时，**奶蛙头顶浮一条紫色百分比**（越接近 100% 越危险，过 65% 变粉并脉动催你），第一次见到会把世界冻住弹一张卡解释这条百分比是什么、怎么破（冲过去打断）。
- **雾鬼显隐差别拉大**（第 65 块）：隐身时透明度压到 **0.05**（几乎只剩轮廓），显形时**自发光从 0.3 拉到 2.2** —— 在浓雾里亮起来比「变不透明」更容易被余光抓住。
- **缝补小巫的奶有了存在感**（第 65 块）：被治的怪身上会**连冒 1.4 秒绿加号**（每 0.16 秒一个，一边往上浮一边变大），隔半个场地也看得出哪只在回血；范围 8.0 格，但不再画那个巨大的判定圈。
- **局外成长**：**夜行商店**一个入口、进去分两区 —— ① 篝火 9 簇无限级火种（每局结算发骨币，越点越贵）；② 盲盒宝箱（木匣首价 30 / 银匣 100 / 金匣 280，**每买一次这种箱子 +5% 首价**（第 82 块从 6% 调下来 —— 连着买同一个箱子涨得太快），三种各自独立计数；开启直接盲抽一次永久属性变化，诅咒率 35%/18%/7% 中了必给负面；银、金还能开出永久法器与技能CD缩短）。永久效果每局开局自动注入；永夜火种 16 张永久卡（本关首通发 3 次三选一）；夜行诅咒 6 条 debuff 换骨币倍率（加法叠加最高 ×2.30）。

## 运行

**加载是按需的（第 72 块 + 第 80 块）**：首屏只拉主角 + 第一关要用的 4 只怪（约 3MB，原来 17 只全拉约 8.7MB）；选了别的关，在「点开始、标题页淡出」那一刻按差集补那一关缺的模型，加载页复用同一层遮罩显示进度。已经加载过的怪不会重复下载，重进同一关零请求。第 80 块又加了三层：

- **并发下载**：原来是 `for + await` 串行，第六关 11 只怪（约 5MB）一只一只排队；现在 4 路并发，同样的量大约 1/3 时间。某一只失败也不再连坐（以前一 reject 整关都进不去）。
- **进关后静默预载下一关**：开局 4 秒后（第一波已经稳住）悄悄把下一关缺的模型拉下来，并发压到 2，不跟战斗抢主线程。真正进关时差集是空的 —— 零等待。
- **进度写清「3/5」**：光有一条不会动的进度条，等超过三秒就会被当成卡死；现在标题里写着「正在进入第六关 · 3/5」。

**进站加载 + Service Worker 本地缓存（第 79 块）**：首屏要拉 **52 个文件 / 约 1MB**（`three.module.js` 一个就 1.2MB 未压缩，38 个 ES module 全部独立请求，这是「无构建 + 零 CDN」的代价，绕不开）。而 GitHub Pages 只给 `Cache-Control: max-age=600` —— 隔十分钟再进就等于重新下一遍，国内直连 6 秒起步。

- 新增根目录 **`sw.js`**：带 `?v=N` 的 js/css 走**缓存优先**（发版铁律是全部一起 bump，所以同一个带版本号的 URL 内容永远不变，永久缓存绝对安全），其它静态资源（glb / webp / 字体 / 音频）走**先给缓存、后台更新**；`index.html` 一律放行，保证发版能立刻拿到新版。同一个版本号内二次进站基本**秒开**。
- 顺带**自动重试**：网络抖动时同一个请求最多试 3 次（退避 250 / 500ms）。以前任何一个依赖请求被掐断，整个模块图就废、游戏直接打不开 —— 这是「偶发白屏」的根源。
- 只缓存**完整成功（200）**的响应；404 原样交回去不重试（重试只是让页面多等 750ms 再拿到一个网络错误）。
- 不支持 SW 的老浏览器（iOS 11.3 以前 / 老 WebView）静默跳过，行为跟以前完全一样。
- **`?nosw=1`** 是后门：完全不经过缓存，也不往里写。SW 万一哪天出问题，玩家 / 我都可以用它绕过。

**加载页的提示也重写了（第 79 块）**：以前是「9 秒没起来就报**加载超时**」—— 那是**误报**，它只代表「9 秒内没跑完」，不代表失败，而且红色小字的颜色字号写死在元素上、后面加载成功了也不还原。现在：

- **9 秒** → 只多一行黄字「网络有点慢，还在加载……」，百分比和进度条照常走，不染红、不判死；
- **25 秒** → 再给一个「重新加载」按钮，但仍然不写死；
- **脚本真的 404 / 解析失败** → 才报红字「脚本加载失败，请检查网络后重试」+ 重试按钮；
- 模块一跑起来（`window.__naiwaBooted`）→ 所有提示自动收掉，文字样式也还原。

**glb 也带版本号了（第 80 块）**：SW 的第 79 块策略只给带 `?v=N` 的 js/css 走「缓存优先」，glb 因为没有版本号只能走「先给缓存 + 后台重下一遍」—— 而怪物模型一共 7MB，**每次刷新、每次重新进关都在后台重下一遍**，玩家进关时带宽被自己抢光。现在新增 `js/assetUrl.js`：`ASSET_V` 从模块自己的 `import.meta.url` 里读（不写死，发版一起 bump），`withV(path)` 给 glb 拼上 `?v=N`。同一版本第二次进站，模型一个字节都不下；换版本 URL 变了，天然拿新模型（第 77 块「换了模型看着像没换」的坑一起堵掉）。

**第六关的并联体重做（第 80 块）**：用户三条反馈 ——「介绍不清晰」「不用成对出现，两个以上就行」「感觉并联体和节点是两个实体，节点在稳定移动、并联体乱转」。查下来最后一条是个真 bug：

- **模型原点离几何体 6 格**。Kenney 的 `machine_generator` 顶点中心在 x≈2 / z≈1.5 格（乘上 3.25 倍缩放就是 6 格多），而电弧、碰撞、血条全按 `e.pos` 算 —— 铁疙瘩飘在六格外、玩家砍的是空气。现在加载时量一次静态网格的包围盒，用一层 `pivot` 把偏移吃进去（**不能直接改 `model.position`**：Three 是 T×R×S，先偏移再旋转，模型会绕着那个偏移点转，摆动 0.16 弧度能甩出 ±1 格 —— 这才是「乱转」的观感）。
- **取消整圈自转**：原来 `model.rotation.y = t × 0.8`，和 root 朝玩家转叠在一起，看着像两个东西。现在只留 ±0.16 弧度的左右机械摆动。
- **两两最小间距 3.0 格**：每帧对每一对做「同性相斥」，靠太近就互相推开（迭代两轮，推完夹回场地）。手机上以前会全挤在主角身边堆成一坨，电弧被压成零长度，禁区成了一个点。
- **电弧重画**：一条线 = 一个 `InstancedMesh`（4 段椭球 + 2 个流光球，1 个 draw call）。折线随相位扭动、光点沿线跑、咬到人时整条爆闪。抬高到模型顶部（原来在半腰，从俯视角被 1.3 格高的铁疙瘩挡住一截），端点从模型边缘起步 —— 线看起来是从铁疙瘩身上长出来的。
- **不必成对**：任意 n ≥ 2 就成网（2 只 1 条、3 只 3 条、4 只 6 条）。第六关第 9 回合特意给了 3 只（奇数）来证明这一点。
- **文案写清机制**：图鉴与「新怪物」卡共用同一份描述 —— n 只连几条、碰到掉 1 点、同一下隔 0.7 秒（站交叉口不会瞬间连扣）、它们之间保持 3 格以上所以中间有活路、拆掉一只它牵的线整片断。顺带给新怪卡的图片加了 `onerror` 兜底：图没了就藏起来，不给玩家看碎图图标（第 75 块就是漏了 `arc.webp`，卡上是个破图）。

**第八关「骨塔寄存层」+ 两只新怪（第 81 块）**：用户选的两套机制 ——「列队推进」和「寄存柜」——不是各玩各的，是串成一个闭环的：**无名者倒下 → 木牌被寄存柜收走 → 柜满 8 块开门 → 把这一沓牌子放回场上，走出来一支新队伍**。正好接上主线 s08「寄存处的骷髅，在等一个永远不会来的队伍」。

- **无名者**（`ranker`，全场唯一不追人的怪）：骨架队列沿**固定方向平移**（`speed 1.05` 是队列平移速度，不是追击速度），朝向 = 队伍方向而不是玩家方向 —— 你跑到它背后它也不回头。**撞到场边才会换向**（朝场地中心 ±20° 扰动，不是纯反向）。队形用**槽位制**：6 个槽位、间距 1.0 格，每只记自己的法线偏移、每帧被拉回，不做物理分离（同队成员跳过分离循环，否则「分离」与「回槽」两套力每帧互相拉扯，队伍抖成筛子）。间距 1.0 必须大于 2×碰撞半径（0.42），不然这两股力注定打架。撞到主角掉血，并把人沿**队伍法线**挤开 —— 沿径向挤会把人一路顶着走、直推到墙角出不来。
- **旗手**（`bearer`，队列中间举木牌那只）：生命 7。砍死它整队**崩散 4 秒**（站住不动、期间受到的伤害 ×2，配一记金色爆发）。所以「先拆旗手，再吃那 4 秒」是这关唯一的正解，一只只砍是最亏的打法；反过来，缝补小巫会把散掉的队伍重新扶起来，是优先清理对象。
- **木牌是程序化贴图，零新资产**：一只胸前挂牌、一只举杆挂牌，全都是 canvas 画的木纹 + 被擦掉的一道划痕（名字被抹掉了，牌还留着）。踩过的三个坑都写进注释了：① 挂件要**反向缩放**（`model.scale ≈ 1.5`，套一层 `holder.scale.setScalar(1/s)` 才能按世界单位写尺寸）；② 牌子必须是**有厚度的 Box**，零厚度 Plane 在队伍侧身走的时候正对镜头变成一条线；③ 材质必须用**不吃光的 `MeshBasicMaterial`** —— 用受光材质会被 `cfg.tint` 整片覆盖颜色、再被 `cfg.glow` 盖一层自发光，最后渲染成一块深棕近黑的小方片，夜里压在深灰地面上**和「根本没画」一模一样**（为这个查了三轮相机投影）。现在 `userData.isTag` 会把木牌从 tint / 材质 clone / 受击闪白里摘出去。旗手杆 2.45 格、牌子悬在头顶上方（y=2.18）且往侧前方偏出 0.60，避开那顶又高又宽的红兜帽；牌顶仍低于血条底边，不会被自己的血条压住。无名者的胸牌挂到 `z=0.56` —— 这只模型胸口自带围巾，0.30 会整个埋进去。
- **寄存柜**（`js/deposit.js`，本块新模块）：立在场地**外面**的哨亭（z=-19.2），3.0×2.2×1.0 柜体 + 顶檐 + 两侧立柱 + 3×3 寄存格柜面（满柜整面发黄光，右下角写着 `n / 8`）。无名者与旗手倒下各掉一块木牌进柜；**攒满 8 块 → 3 秒开门倒计时 → 放出一支 6 人新队伍**（自带旗手），从柜子前一排走出来。开门前站到柜边**站桩 1.1 秒**（位移超过 0.035 格就断，被队伍撞一下就得重来）能先取走 **2 块**。场上队伍人数 ≥ 12 时不再放人，改成**放电**：地上先亮一圈橙光预警 1.5 秒，然后 8 格内 3 点伤害 —— 攒牌攒过头不是纯赚。
- **柜子为什么放在场地外**：队伍换向点在 r=16.1，永远碰不到它，不会出现一排骷髅从柜子里穿过去的穿模；而玩家走到场地边缘（r≈17.7）离柜子才 1.5 格，正好在取牌范围（3.4）里。
- **主题 `ossuary`**：骨白 + 灰绿 + 干燥白雾。地面贴图三层细节叠出来 —— 踩亮的石面、3200 个骨渣点（38% 以上是骨白）+ 150 根碎骨条、26 个**散位且微歪**的木牌压痕（摆成等距阵会立刻看出是瓷砖）。
- **关卡数据**：arena 18，20 回合 5 幕（寄存层 → 柜子满了 → 拆旗手 → 两个机制一起压 → 毕业考）。R2 起就有队伍，R8 起两队，后期封顶 12 无名者 + 3 旗手。图鉴里这两只不走「追人」那套说明，改显示**队列移速 / 不追人 / 散架 4 秒**。剧情 s08 绑在第八关第 2 回合。

**第 82 块（本块）：四条用户反馈 + 第九关**

1. **并联体的两两间距改成「实时」硬约束**：原来 `minGap 3.0` 是**软推**（每帧只补 15% 的差额，而追击每帧把它们压近 0.05+ 格，稳态距离实测只有 2.6 出头）—— 用户量到的「实时距离」就是那个数。现在① 每帧把差额**补满**（只有单帧限速 9.5 格/秒，比追击快 5 倍），② 迭代 4 轮（三只互相抵消时收敛），③ 新并联体落地即 `seatArc` 摆到合规位置（不然刚冒出来那 0.8 秒是贴在一起的两块铁疙瘩），④ `minGap` 3.0 → **8.0** —— 一条电弧横跨小半个机房。顺带**血量 3.2 → 12**：禁区必须「拆得起但拆得慢」，一刀就断的话网等于不存在。
2. **电路伤害无视无敌时段**：电弧命中走 `hurtPlayer(dmg, 'arc')`，和漏电地板的 `'hazard'` 一起归入「不吃无敌帧、也不给你刷无敌帧、不触发棘甲反伤」，但**仍然吃防御**（它还是「怪在电你」，不是地形）。无敌帧里被泡/电弧擦过去不会再出现「我明明闪过去了」的判定感。
3. **盲盒涨价 6% → 5%**：`BOX_PRICE_STEP`。木匣第 20 次 66 → 60，金匣第 10 次 448 → 420。线性加价本来就该慢慢收。
4. **木鱼灵换掉和咒面图腾重合的攻击模式**：它原来是整套照抄（同样是 `spell.kind:'hex'`，连 windup / attackInterval 都一样，只是把紫色换成青色）—— 玩家眼里就是「换个颜色的同一只怪」。现在是**吐追踪泡**：一颗实体泡慢慢追你（2.6 格/秒，你 4.4；转向只有 1.2 弧度/秒，绕圈能遛），**有 4 点血、砍两下就炸**，追上是 1 点伤害并把你**定住 1.2 秒**（一步都走不了 —— 比咒面图腾的减速狠得多，减速还能挪）。前七关已经有四种「地上画个圈、圈亮了掉血」，再叠一个同类的只会让人麻木；泡换的是另一个维度：要**处理**一个追着你的东西，不是躲一片地。

**第九关「骨塔登记庭」+ 称量官**：接剧情 s09《名字的重量》—— 第九十九层的门上嵌着一本簿子，门卫 047 说「到这儿就得上称了，这道门认字」。

- **称量官**（`weigher`）：抱着一本台账、站得极远（keepDistance 7），自己几乎不打人，活儿是**给全场记账** —— 每隔 9 秒翻一次簿子，场上**所有**存活的怪一起加移速 +7% / 伤害 +9% / 减伤 +5%，最多 **5 层**；后上场的怪同样带着当前的层（这一层的规矩不认「你刚来」）。
- **明显特效**：① 前摇一圈金色大环从它脚下扩到整个场地；② 结算时每只被记名的怪脚底炸一朵金花、长出一只**金环**（半径随层数长大，一眼数得出第几层）；③ **砍掉它 → 所有金环同时炸开、层数当场清零**，这是这一关唯一的正解，所以输出窗口只有它站定念簿子那 2.2 秒。
- **为什么做「全场」而不是「点一只」**：点名只有一只是可以无视的（打别的就行），全场叠层绕不过去，只能把它拆掉 —— 压力直接指到它身上。第三幕起上两只、第五幕三只：「绕后拆它」不再是单选题。
- **第九关不额外加数值**：`hpMul 1.28 / dmgMul 1.55` 和第八关同档，压力全部来自那五层等差数列；再叠一关的数值会让后期彻底失控。
- **模型故意复用** `hooded-scribe.glb`（第五关擦名者那只）：兜帽长袍 + 一本程序化台账（canvas 贴图 + 两道金色捆绳）就是「记账的」，第五关那身紫黑和这一身鎏金一眼能分开；第八关的无名者/旗手已经开过这个先例。零新资产。
- **主题 `registry`**：鎏金 + 墨。地面是墨色石板 + **鎏金勾缝** + 散落的簿角纸片 + 记数划痕 + 金粉（石板位置微抖 —— 排成等距网格平铺 16 次会立刻露周期）。

浏览器不允许 `file://` 下的 ES Module 与 fetch，不能双击 index.html，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000
# 然后打开 http://127.0.0.1:8000/
```

部署到任何静态托管（GitHub Pages / Netlify / Nginx）都是「整个仓库根目录当站点根」，无需构建。
