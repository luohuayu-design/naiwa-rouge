# 蛙步 · 夜行（naiwa-rouge）

Three.js 做的**幸存者类肉鸽**。主角是「奶蛙」，来自同作者的音游《蛙步》。纯静态站点（无构建、无 CDN、零依赖，Three.js r160 本地内置），GitHub Pages 发布，**手机浏览器兼容是硬约束**。

在线试玩：<https://luohuayu-design.github.io/naiwa-rouge/>

**当前 v=139（第 122 块）**
- **回合挑战**：每关随机 2 个回合，在开打**前**弹一张挑战卡（残血 / 绵软 / 断剑 / 怪物潮 / 疾风 / 冷手 / 禁术 / 沉重 / 破防），可以放弃但没奖励；打完弹奖励三选一（88 金币 / 再来一次三选一 / 下一回合属性大涨）。
- **三选一可刷新**：一局 3 次免费；之后每次刷新要**随机背一条盲盒减成**（属性掉一截、整局生效、不可撤销，十条背满就不能再刷了）。
- 上一版（第 121 块）修了 **连杀被暂停时间冲掉**：断连计时改接局内战斗秒表，在商店 / 对话 / 背包里停多久都不再掉热度。

**回合事件一览**见 [`关卡事件表.txt`](关卡事件表.txt)（脚本从代码生成，含升级概率 / 商店价目 / 元素剑图鉴 / 随机事件表）。

## 玩法

- **开局**：加载完进标题页 → 选关卡（通关上一关才解锁）→ 选难度 / 诅咒 → 是否看教程 → 开打。每关 **20 回合**，清完通关、生命归零倒下。第一关 20 回合共 273 只怪，第 20 回合怪物生命 ×4.04 / 伤害 ×2.90 / 移速 ×1.86 / 出手间隔 ×0.69。
- **移动**：深夜草地圆形竞技场（可走半径 15~20，撞边沿切向滑走）。左半屏按住拖出浮动摇杆，WASD / 方向键也可用。
- **自动近战**：范围内自动出手（频率 = 攻速），脚下青环就是攻击范围 —— 走位是把怪**带进圈里**，不是追着砍。骷髅也都画自己的圈：小兵暖橙自爆圈、战士红近战圈。
- **三选一成长**：每回合清空后冻结世界弹三张卡（**109 张**、五档品质 = 抽签权重），显示「原值 → 选后值」。**底部有一颗刷新键**：一局 3 次免费换一批；三次之后变成橙色的「用一条减成换一次刷新」，代价写在键上。
- **回合挑战**：每关随机 2 个回合，开打前弹卡，接下就按它的规矩打这一回合，放弃则照常打、没有奖励。九条：残血（上限 ×0.5）/ 绵软（攻击 → 40%，最低 1）/ 断剑（剑整把失效）/ 怪物潮（数量 ×2）/ 疾风（怪移速 ×1.45、出手 ×1.3）/ 冷手（攻速 ×0.55）/ 禁术（技能全锁）/ 沉重（移速 ×0.62）/ 破防（受伤 ×1.6）。打完弹**奖励三选一**：88 金币 / 立刻再一次三选一 / 下一回合属性大涨（基础属性 + 技能 + 法器各一条，**只活一回合**）。
- **随机事件**：**131 个**（99 随机 + 10 条主线番外 + 13 连锁后续 + 9 民心专属），同事件 3 回合不重复，效果落下一回合。**「只活一回合」的临时数值统一放大到约 1.5~2 倍同档永久卡**（攻击 0.6 / 移速 20% / 暴击 8%→16% / 怪量 ±30%），否则没人会选。**民心**（0~120，开局 50）影响商店价 0.65~1.25×、金币掉落 ±8%，涨跌档会触发专属事件。播放时机：随机事件 → 三选一 → 民心事件 → 商店，全在这一回合的结算链里。
- **金币 / 商店**：打死怪概率掉金币（落地 3 秒入账，进范围自动拾取）。每 3 回合弹商店摆 4 件（**40 件货**），同件一次进店只买一件；可花骨币刷新（6 / 10 / 15 / 25 / 39，本次进店递增）。
- **装备**：弩炮台（上限 3，自主索敌）、**14 件法器**（地刺 / 霜环 / 震钟 / 棘甲 / 暖炉 / 路口灯 / 绝缘斗篷 / 木鱼 / 镇牌铃 / 傀儡术 / 墨丸 / 苔藓拿铁 / 守夜烛 / 落款，各 3 级）、金钟罩、背包（B 键，药水入包再喝）。部分法器**只在特定关卡出售**（绝缘斗篷只在第六关、镇牌铃只在第八关 —— 离开本关的机关它们没用）。
- **元素剑**：6 种（铁 / 毒 / 冰 / 雷 / 血 / 震），**除铁剑外全是群体**：毒冰血震波及 7.0 格一圈（冰定身 1.6s / 毒 0.15 每秒 / 血按一圈总伤回血 / 震 35% 击退），雷剑全场连锁（每道 45%）。环剑 3 把环绕、数量无上限。
- **技能栏 8 格**：万剑齐发 / 箭雨 / 回血 / 傀儡 / 墨丸 / 拿铁 / 守夜烛 / 落款。**技能只看「解锁」不看「第几关」** —— 永久解锁过，任何关卡开局都带着。
- **局外成长**：① 篝火（23 簇无限级，每局结算发骨币）；② 永夜火种（16 张永久卡，首通发一次三选一）；③ 盲盒宝箱（木 30 / 银 100 / 金 280，每买同一个箱子涨价 3%，开出永久属性 / 法器 / 技能 CD）；④ 夜行诅咒（6 条，**开局自选**，换骨币倍率、最高 ×2.30 —— 和刷新那种「抽到的减成」不是一套：后者只在本局掉属性，不给任何补偿）。
- **存档**：每回合自动落档，顺便留一份**本机备份**（只留最近 3 份，设置里可恢复）。设置里可**导出文件**（纯 ASCII 名）/ **复制存档码**（`NWSZ1:` 压缩码）/ **导入文件** / **粘贴存档码**。浏览器保不住 `localStorage` —— 清缓存 / 无痕 / 换设备时只能靠这条手动备份的路。
- **其他**：八步新手教程 + 每种武器只教一次；每日签到（周一开周，每天随机 0~100 骨币，3 / 5 / 7 天里程碑）；礼包兑换（51 码，只存哈希）；图鉴 / 成就（**118 条**，解锁后手动领骨币）/ 攻略面板；主线《笑不出来的那一夜》18 夜约 2.3 万字、三印记四结局；帧率自适应（连 2 秒低于 40 帧自动降档，稳 5 秒再升回你选的那档）；管理员模式（调试用，不落盘）。

## 运行

浏览器不允许 `file://` 下跑 ES Module 与 fetch，**不能双击 index.html**，起个静态服务器即可：

```bash
# 在仓库根目录
python -m http.server 8000   # 打开 http://127.0.0.1:8000/
```

部署到 GitHub Pages / Netlify / Nginx 都是「整个仓库根目录当站点根」，**无需构建**。

- **按需加载**：首屏只拉主角 + 第一关要用的 4 只怪（约 3MB，全拉是 8.7MB）；点了别的关，在标题页淡出那一刻按差集补模型，4 路并发；开局 4 秒后静默预载下一关，真进关时零等待。
- **Service Worker（`sw.js`）**：带 `?v=N` 的 js/css 缓存优先（发版铁律是全部一起 bump，同 URL 内容永不变），glb / webp / 音频先给缓存后台更新，`index.html` 一律放行保证发版立刻生效；网络抖动时同一请求最多重试 3 次。**`?nosw=1`** 是完全绕过缓存、也不写入的后门。
- **glb 也带版本号**（`js/assetUrl.js` 从 `import.meta.url` 读 `ASSET_V`），同版本二次进站模型一个字节都不下。
- **加载页兜底**：连续 6 秒没有新 js 下完才判定卡死并自动重载（同一 tab 最多 2 次），还在慢慢下载就绝不打断；重载两次仍起不来才给「重新加载」按钮。游戏启动后还会自检版本号，发现线上有新版本会自动刷新一次（局内 / 设置 / 属性页开着时不刷）。

## 目录结构

```
naiwa-rouge/
├── index.html              # 入口：画布 + 触摸层 + 摇杆 / HUD / 各面板
├── style.css               # 深色 UI 全量样式
├── sw.js                   # Service Worker（必须在根目录：scope 要覆盖全站）
├── 关卡事件表.txt / 每日任务池.md / DESIGN.md
├── assets/                 # 奶蛙 rigged.glb / weapons / monsters(24 glb) / golems / props / codex(27 webp) / audio
├── lib/                    # three.module.js r160 + GLTFLoader / SkeletonUtils（本地内置）
└── js/                     # 64 个 ES module（主循环 main / wave / stats / enemy / weapon / shop / events / 各系统）
```
